# TabiTrace 移动端 Travel Story 视频制作页面重构指令

你现在作为当前「旅迹 / TabiTrace」项目的高级前端工程师、移动端 UI/UX 工程师和 Travel Story 功能工程师。

请基于当前已经存在的：

**旅行详情 → 分享 → 视频 / Travel Story**

进行一次完整的移动端页面重构。

本次任务主要针对移动端布局和操作体验，不是重新开发视频生成功能。

请先检查当前真实代码、组件、API、Worker、视频模板与媒体素材数据结构，然后直接修改并测试。

## 一、核心任务

当前页面已经具备：

- 视频模板选择
- 照片素材选择
- 内容与风格配置
- 背景音乐
- 导出比例
- 视频清晰度
- 视频时长
- 生成确认
- 实时预览
- 视频生成
- 我的视频

这些业务功能必须保留。

当前移动端的问题是：

1. 五个制作步骤全部纵向展开，页面过长。
2. 视频预览位于页面下方，无法及时观察编辑效果。
3. 模板卡片纵向排列，占据大量空间。
4. 照片素材缩略图较小，选中与排序不够直观。
5. 内容设置、视频风格和背景音乐集中在一个长模块里。
6. 音乐列表过长，影响正常编辑流程。
7. 导出设置和生成按钮距离较远。
8. 用户需要频繁上下滚动。
9. 我的作品和当前视频制作流程缺乏明确区分。
10. 整个页面仍然保留较多桌面端纵向堆叠的特征。

本次重构目标：

将页面升级为真正适合手机操作的：

**Mobile Travel Story Studio**

设计原则：

预览优先、分步制作、减少滚动、操作聚焦、状态清晰。

## 二、必须遵守的限制

本次主要修改 Mobile 布局。

Desktop ≥1024px 已有布局尽量保持不变。

不要：

- 创建新项目。
- 重新开发视频生成 Worker。
- 更换现有技术栈。
- 重建 Video / Trip / Photo 数据库。
- 删除原有视频配置能力。
- 使用假的视频生成结果。
- 将全部现有功能改为静态展示。
- 新增没有后端能力的导出选项。
- 重复创建 Desktop / Mobile 两套业务逻辑。

优先复用当前组件、Hooks、Service 和 API。

## 五、视频预览区域（重要）

将当前位于页面下方的 Live Preview 移动至主要编辑区域顶部。

模块名称：

**视频效果预览**

展示内容：

- 当前视频封面。
- 当前旅行标题。
- 当前模板效果。
- 当前选择的画面比例。
- 预计视频时长。
- 当前背景音乐（如果已选择）。
- 展开预览按钮。

预览必须与当前编辑状态关联。

例如：

修改标题 → 更新预览文字。

切换模板 → 更新模板预览。

修改视频比例 → 更新预览容器比例。

调整素材 → 更新预览素材。

注意：

编辑时可以使用现有 Storyboard / Canvas / 前端模拟预览机制。

但是必须明确区分：

效果预览 ≠ 最终 Worker 生成的视频。

不要把未实际生成的前端效果标记为正式成片。

移动端不要让一个完整竖屏 9:16 视频预览占据整个首屏。

建议：

普通预览高度约 240～300px。

同时提供：

展开预览 / 全屏预览。

视频比例需要真实适配：

9:16

16:9

4:5

具体保留当前项目已经支持的比例。
