你现在作为当前「旅迹 / TabiTrace」项目的高级全栈工程师、前端架构工程师和开发工具工程师。

请在当前项目中实现一个：

Dev Data Switcher / 开发数据源切换器

仅在本地开发环境显示。

用途：

开发和调试时，可以在页面顶部快速切换整个应用当前使用的数据来源：

1. 本地数据库数据
2. Mock 模拟数据
3. Empty 无数据模式

正式 Production 构建和线上页面：

绝对不能显示这个按钮，
也不能暴露开发数据切换入口。

不要创建新项目。
不要重写当前业务 API。
不要让每个页面分别实现自己的 Mock。
请先检查当前项目的数据请求架构、状态管理和环境配置，然后直接实施。

==================================================

==================================================

写入 dev memory store。

请选择最符合当前架构的方式。

核心原则：

Empty / Mock 不允许误写 Local DB。
