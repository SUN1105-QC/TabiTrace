# 「旅迹」旅行成果海报 AI 作成指令

请只重新设计并实现**旅行成果海报本体**。

不要修改或生成：

* 页面 Header
* 左侧 Sidebar
* 导航 Tabs
* 导出 PNG 按钮
* 右侧分享设置
* Trip Pro 卡片
* 页面背景
* 海报外部容器

最终只需要输出一张完整的：

> **东京旅行成果海报**

---

## 1. 整体设计方向

将海报设计成：

> **日系旅行手帐 × Editorial 杂志排版 × 旅行摄影 × 纸张拼贴**

不要做成普通旅行宣传海报，也不要做成九宫格。

关键词：

```text
Japanese Travel Journal
Editorial Travel Poster
Tokyo Travel Notes
Analog Scrapbook
Minimal Japanese Magazine
Paper Texture
Photography Collage
Quiet Luxury
Warm Nostalgia
```

整体应该有一种：

**“旅行结束后整理出来的一页私人旅行笔记”**

的感觉。

视觉气质：

* 安静
* 克制
* 文艺
* 温暖
* 有生活气息
* 有摄影杂志感
* 有轻微手工拼贴感
* 不过度商业化

---

# 2. 海报比例

使用竖版海报。

推荐比例：

```text
3 : 4
```

或者：

```text
900 × 1200
```

用于实际网页生成时：

```text
width: 760px ~ 840px
```

高度根据比例自动计算。

不要做成长图。

---

# 3. 海报背景

整体使用：

```text
暖米白
象牙白
旧纸张色
```

推荐：

```text
#F6F2E9
#F4EFE5
#FAF7F0
```

增加极轻微：

* 纸张纹理
* 胶片颗粒
* 印刷纹理
* 泛黄效果

但是纹理透明度必须非常低。

不要做成明显复古旧报纸。

---

使用**非对称 Editorial Split Layout**。

大致结构：

```text

│                                 │
│   旅行文字区       大幅摄影图区   │
│                                 │

│   旅行文字                      │
│                                 │
│─────────────────────────────────│
│                                 │
│   旅行数据                       │
│                                 │

│                    路线地图      │
│                                 │
│                 品牌署名         │
```

需要有明显的：

* 主视觉
* 次视觉
* 留白
* 内容节奏

# 5. 左上：旅行标题区域

左上区域占海报约：

```text
40% ~ 45%
```

顶部放一个小型英文眉题：

```text
TRAVEL NOTES
```

使用：

* 大写英文
* 字距较宽
* 细字重
* 深墨绿色 / 深灰色

下面放主标题：

```text
我的
东京旅行
```

采用上下两行。

字号明显放大。

推荐使用：

* 中文宋体
* 高级衬线字体
* 日系出版物风格字体

不要使用粗黑无衬线字体。

颜色：

```text
#26372F
```

或深墨灰。

# 7. 日期

继续显示：

```text

```

排版简洁。

字号不要过大。

使用较大的 Letter Spacing。

---

# 8. 旅行文案

日期下增加一段类似手写旅行笔记的文案：

```text
“在熟悉又陌生的城市里，
收集一些会发光的日常。
东京，总有新的故事等着我。”
```

这部分可以使用：

* 手写字体
* 仿手写排版

但必须保证：

**中文可读。**

不要使用太潦草的字体。

可以稍微旋转：

```text
-1deg
```

产生自然手帐感。

---

# 9. 右上：主摄影作品

右侧约占：

```text
55%
```

使用一张大幅旅行照片。

照片主题建议：

> 东京安静街区的坡道，远处可以看到东京晴空塔或东京城市天际线。

画面特点：

* 下午阳光
* 自然树影
* 日系街区
* 低饱和摄影
* 有空间纵深
* 少量人物或者无人
* 真实摄影质感

不要使用：

* 过度旅游宣传照
* 高饱和网红滤镜
* 赛博朋克东京
* 大量霓虹灯

这张图应该体现：

> **“真正走进东京生活里的旅行”**

---




---

# 26. 图片不足时的处理

如果用户只有：

```text
1张照片
```

则：

* 主图使用该照片
* 下部 Polaroid 减少为 1 张
* 地图区域扩大

如果有：

```text
2张照片
```

使用：

* 1 张主图
* 1 张 Polaroid

如果：

```text
>= 3张
```

使用：

* 1 张主图
* 2 张精选照片

绝对不要因为图片不足导致空白图片框。

---

# 27. 文案缺失时

如果用户没有旅行描述：

不要显示空 textarea 或占位符。

自动隐藏文案模块，或者使用非常简单的旅行日期信息补位。

不能自动生成虚假的用户经历。

---

# 28. 导出要求

整个海报必须位于独立：

```text
PosterCanvas
```

组件中。

导出 PNG 时：

只导出 PosterCanvas。

不要包含：

* 页面背景
* Tabs
* 按钮
* Header
* 外层阴影
* 编辑控制器

建议导出：

```text
2x / 3x
```

高清分辨率。

图片必须：

```text
object-fit: cover
```

保证裁切一致。

---

# 30. 最终视觉目标

最终效果应该更接近：

> **MUJI 旅行手帐 + 日本独立旅行杂志 + 摄影集扉页 + 私人 Scrapbook**

而不是：

> 旅行 App 的统计页面。

用户导出 PNG 后，即使完全不知道这是一个 Web 产品，也应该觉得它是一张完整设计好的：

**私人东京旅行纪念海报。**
