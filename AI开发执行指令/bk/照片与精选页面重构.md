==================================================
目标
==================================================

当前页面存在：

1. 左侧 Upload Form 占用大量页面高度。
2. 照片才是核心内容，却只有约一半页面空间。
3. 原生 file input 暴露在产品 UI 中。
4. Gallery 只有简单 3 列照片墙。
5. 所有图片一直显示“精选”和删除按钮。
6. 精选照片没有明确业务价值说明。
7. 上传、整理、精选、删除等动作混在一起。
8. 缺少批量操作。
9. 缺少 Photo Detail。
10. 缺少按旅行日期组织照片的能力。
11. 页面在照片数量增加后会非常难使用。

请将页面重构为：

Travel Gallery / 旅行照片工作台。

核心流程：

查看照片
→
按日期 / 类型整理
→
精选照片
→
用于分享成果 / Travel Story

上传只是其中一个动作，而不是页面主体。
