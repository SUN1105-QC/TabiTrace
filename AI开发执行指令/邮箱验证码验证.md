==================================================
二、验证码规则
==================================================

默认建议：

6 位数字

有效期：
10 分钟

重新发送：
60 秒

最大错误尝试：
5 次

但如果项目已有统一 Security Config：

优先使用已有配置。

验证码：

必须使用安全随机数生成方式。

禁止使用：
Math.random()

如果没有 Redis：

不要为了这个功能强行引入新基础设施。

可以使用当前数据库。

==================================================

==================================================
五、验证 API
==================================================

新增：

POST /api/auth/email-verification/verify

请求：

email
code
purpose=register

服务器检查：

verification exists
not expired
not consumed
attempts < maxAttempts
hash match

失败：

成功：

返回：

emailVerificationToken

Token 必须：

短时有效
绑定 email
绑定 purpose=register

不能用于其他邮箱。
