# 前端架构设计

代码：`frontend/`。版本以 `package.json` 为准（Next.js 16.3.3、React 19.2.0、TypeScript 5.7 strict、Tailwind 3.4）。
⚠ Next.js 16 与常见版本有不兼容改动，写代码前读 `frontend/AGENTS.md` 和 `node_modules/next/dist/docs/`。

## 1. 目录

| 目录 | 职责 |
|---|---|
| `app/` | App Router 页面与布局（22 个 `page.tsx`）；`globals.css`（全局样式，约 4950 行）；`health/route.ts`（健康检查）；`robots.ts`；`home-client.tsx`（首页客户端部分） |
| `components/<功能>/` | 按功能分目录的组件：`common`（外壳与通用）、`home`、`landing`、`trip`、`map`、`checkin`、`gallery`、`share`、`video`、`explore`、`memories`、`settings`、`pro`、`membership`、`mobile`、`auth` |
| `services/` | API 层：`api.ts`（请求、令牌刷新、错误）、`tabitrace-api.ts`（业务接口与类型）、`video.ts`、`user-music.ts`、`memories.ts` |
| `hooks/` | 页面数据 hooks（`useHomeData`、`useExploreData`、`useTripDetailData`、`useTripSummaryData`、`useUserMusic`）与通用 hooks（`useRequireSession`、`useMediaQuery`、`useMusicPlayer`） |
| `utils/` | 纯业务逻辑（可单测）：套餐、分享图排版、视频、照片尺寸、时间轴、设置校验等 |
| `lib/` | 运行环境（`env.ts`）、站点地址与元数据（`site.ts`）、地图底图（`map-tiles.ts`）、时间、偏好 |
| `types/` | `video.ts`、`user-music.ts`；其余类型和 API 定义写在 `services/tabitrace-api.ts` |
| `i18n/` | zh-CN / en-US / ja-JP 文案（只覆盖部分界面） |
| `constants/` | `app.ts`（含 `LEGAL_LINKS`）、`place-images.generated.json`（脚本生成的景点图清单） |
| `dev/` | 开发数据层（Local / Mock / Empty）与 Mock 数据、音乐版权后台；生产构建剔除 |
| `scripts/` | MapLibre worker 复制（predev / prebuild 自动运行）、景点图优化、图片审计 |
| `tests/unit/` | Vitest 单元测试 |
| `public/` | `images/`（含 `explore/hd/{640,1280,1920,2560}` 四档 WebP、`landing/` 截图）、`brand/`、`generated-videos/`（本地成片，不进 Git） |
| `assets-src/places/` | 景点原图（不进 Git）与 `SOURCES.json`（来源、作者、许可证） |

## 2. 页面组织

- 需要交互的页面写 `'use client'`（22 个页面中 17 个是客户端组件）；页面数据大多在客户端用 hooks + services 获取。
- 需要登录的区域由布局里的 `SessionGate` 保护：`app/trips/layout.tsx`、`app/profile/layout.tsx`。其他页面（如回忆）在未登录时由 API 返回 401，`services/api.ts` 统一跳转登录页。
- 元数据：公开页面用 `lib/site.ts` 的 `publicPage()`（canonical + OpenGraph），私人页面和分享页 `noindex`。
- 首页 `/` 根据是否有会话标记切换：未登录显示 Landing，登录后显示工作台。

## 3. 状态管理

**没有全局状态库。**
| 状态 | 方式 |
|---|---|
| 服务端数据 | 页面 hooks 调 services，组件内 `useState` 保存；没有 SWR / React Query |
| 当前用户 | `userApi.me()` 5 秒内合并重复请求；保存后广播 `USER_UPDATED_EVENT`，外壳据此刷新 |
| 语言、时区 | `PreferencesProvider`（Context），首屏用 cookie 值，登录后以数据库值为准 |
| 快速打卡 | `QuickCheckInProvider`（Context），全站一个入口 `openQuickCheckIn()` |
| 本机辅助状态 | localStorage：`tabitrace-session`（登录过标记，不含凭证）、`tabitrace-live-trip-id`（最近打开的旅行）、`tabitrace-notifications-read-at`；退出登录时清除 |

## 4. API Client（`services/api.ts`）

- 地址：开发默认直连 `http://localhost:8080/api/v1`（可用 `NEXT_PUBLIC_API_BASE_URL` 改）；生产默认同源 `/api/v1`。
- 访问令牌只在内存；请求前若没有令牌但有会话标记，先静默刷新；401 时刷新一次（多标签并发时最多重试 2 次）并重放原请求；仍失败则清会话并跳转 `/login?next=…`。
- 20 秒超时（`REQUEST_TIMEOUT`）；网络不可达（`NETWORK_ERROR`）；业务错误抛 `ApiError(message, status, code, details)`。
- 开发环境先经过开发数据适配层（Mock / Empty 模式直接作答）；生产构建里这段代码不存在。
详见 [认证设计](../07_security/01_认证设计.md)。

## 5. 关键技术点

| 主题 | 做法 |
|---|---|
| 地图 | `components/map/`：MapLibre GL（WebGL）为主，不支持 WebGL 时用 Leaflet；底图由 `lib/map-tiles.ts` 统一提供（生产必须配置服务商，见 ADR-007） |
| 分享图 | `components/share/` + `utils/share-*.ts`：DOM 排版后用 html-to-image 导出 PNG；清晰度、水印按 `GET /plans/trip-pro` 返回的规格 |
| 图片 | 官方景点图用 `PlaceImage`（next/image + 自定义 loader，四档 WebP）或 `hdImage(slug, 宽度)`；用户照片用 `<img>` + `srcset`（thumb / medium / 原图）；大图在被 CSS 隐藏的一端不下载 |
| 照片上传 | `stageTripPhoto`：浏览器先生成 thumb（640 框）和 medium（1600 框），再逐个预签名上传 |
| 视频工作台 | `app/trips/[id]/video` + `components/video/`：草稿配置、分镜预览、轮询生成进度 |
| 多语言 | `i18n/index.ts` 的 `tr()` / `translate()`；找不到时回退中文再回退键名。只有 22 个文件使用，大部分文案仍是中文硬编码 |
| 环境判断 | 只用 `lib/env.ts`（`isDevelopment`、`loadDevDataAdapter`、`defaultApiBase`），业务代码不直接读 `NODE_ENV` |
| 生产构建前置条件 | 必须提供 https 的 `APP_URL`（否则构建失败）；没有地图底图配置时构建日志警告 |
