# 组件设计

只记录**可复用或核心**的组件；普通业务组件看代码即可。新功能需要类似能力时先复用这里的组件。

## 1. 外壳与会话

| 组件 | 位置 | 用途与约定 |
|---|---|---|
| `SessionGate` | `components/common/SessionGate.tsx` | 包住需要登录的页面：确认登录前不渲染个人数据，未登录跳登录页。用在 `trips`、`profile` 布局 |
| `AppSidebar` / `AppHeader` / `SiteHeader` / `SiteFooter` | `components/common/` | 桌面侧栏、工作区顶栏、公开页顶栏与页脚 |
| `PageContainer` | `components/common/PageContainer.tsx` | 所有页面内容的宽度容器，`variant`: `wide` / `medium` / `narrow`（见 UI 规范） |
| `PreferencesProvider` | `components/common/PreferencesProvider.tsx` | 语言、时区的运行时来源 |
| `GlobalSearch` | `components/common/GlobalSearch.tsx` | Ctrl/Cmd+K 功能搜索 |
| `NotificationCenter` | `components/common/NotificationCenter.tsx` | 站内通知（前端根据现有数据计算，已读时间存本机） |
| `DevDataRoot` | `components/common/DevDataRoot.tsx` | 只在开发环境挂载开发数据源切换器 |

## 2. 通用 UI

| 组件 | 用途与约定 |
|---|---|
| `ConfirmDialog({ title, body, actions, onCancel })` | 站内统一确认框；危险操作必须用它，不用浏览器 `confirm` |
| `PlaceImage` | 官方景点图：next/image + 自定义 loader，按 `sizes` 在四档 WebP 中选择；父元素负责宽高比和 `position: relative` |
| `ImageCredit({ url, label })` | 官方图的作者 · 许可证 · 来源；不是官方高清图时不显示 |
| `TripCoverImage({ trip, alt, loading, compact, sizes })` | 旅行封面；没有封面画暖色渐变封面，不再使用示例图 |
| `Brand` | 品牌标识 |

## 3. 业务核心

| 组件 | 位置 | 用途与约定 |
|---|---|---|
| `QuickCheckInProvider` / `useQuickCheckIn()` | `components/checkin/` | 全站唯一的快速打卡入口 `openQuickCheckIn(tripId, prefill, { camera })`；需要直接唤起相机时必须在同一次点击里同步调用 |
| `MembershipGate({ feature, membership, readOnlyChildren })` | `components/membership/` | 会员功能的统一门槛，前端判断只走这里和 `utils/membership.ts` |
| `VideoProGate` / `PlanBadge` | `components/video/VideoProGate.tsx` | 行内 Pro 提示与 FREE / PRO 标识 |
| `LiveTripSubnav` | `components/trip/` | 旅行子页面导航 |
| 地图组件 | `components/map/`（`LiveTravelMap`、`workspace/TripMapCanvas` 为 MapLibre；`LiveBasicMap`、`workspace/TripBasicMap` 为 Leaflet 回退） | 底图配置统一来自 `lib/map-tiles.ts` |
| 分享成果 | `components/share/` | 海报、九宫格（标准 / 旅行手帐）、每日长图；导出逻辑在 `utils/share-export.ts`，规格来自方案配置 |
| 视频工作台 | `components/video/studio/`、`components/video/music/` | 步骤、模板、素材、音乐选择（曲库 / 我的音乐）、分镜时间线、生成面板 |

## 4. 约定

- 组件 PascalCase，文件名与组件同名；放在所属功能目录，通用的才放 `common/`。
- 组件不直接 `fetch` 后端，统一调用 `services/`。
- 套餐限制、价格、视频规格不在组件里写死，读方案配置（`utils/plan.ts`）。
- 用户可见文案目前多为中文硬编码；新增需要多语言的文案放进 `i18n/` 三个语言文件。
