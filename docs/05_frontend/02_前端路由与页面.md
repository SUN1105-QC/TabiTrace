# 前端路由与页面

合并了原 `frontend/docs/ROUTE_API_MATRIX.md`（09-18，已过期删除）。2026-11-02 按 `frontend/app/`、`next.config.ts` 与各页面实际调用的 API 核对。
权限：**公开** = 不登录可访问；**登录** = 由 `SessionGate` 或 API 401 拦截；**令牌** = 凭分享令牌访问。

## 公开页面

| 路径 | 页面目的 | 权限 | 主要数据来源 |
|---|---|---|---|
| `/` | 未登录：产品介绍（Landing）；登录后：个人工作台（当前旅行、日历、统计、最近记录、今天可以做） | 公开（内容随登录态变化） | 登录后：`useHomeData`（旅行、打卡、行程、照片、总结、分享、视频、官方地点） |
| `/login` | 登录；支持 `?next=` 回跳（只允许站内路径） | 公开 | `POST /auth/login` |
| `/register` | 邮箱验证码注册 | 公开 | `/auth/email-verification/send` `verify`、`POST /auth/register` |
| `/forgot-password` | 找回密码 | 公开 | 验证码 + `POST /auth/password-reset` |
| `/explore` | 推荐探索入口：国家主题 → 城市卡片；可按国家、城市中英文名、主题关键词和开放状态筛选，条件保留在地址栏。只有已开放的城市有入口，预告城市只显示状态 | 公开 | `GET /official-cities/directory`（`useExploreDirectory`） |
| `/explore/tokyo` | 东京城市指南：面包屑可返回国家目录；地点、区域、旅行灵感；登录后可收藏、加入旅行 | 公开（操作需登录） | `useExploreData`：官方地点、专题路线、收藏、当前旅行地点 |
| `/explore/seoul`、`/explore/hong-kong`、`/explore/taipei` | 首尔、香港、台北城市指南，与东京共用 `CityExplorePage`（城市配置在 `constants/explore-cities.ts`）；分享链接、登录回跳、全局搜索的官方地点都回到所属城市 | 公开（操作需登录） | 同上，按城市代码 `SEOUL` / `HONGKONG` / `TAIPEI` 请求 |
| `/pricing` | Trip Pro：权益、价格、对比、FAQ；按未登录 / 免费 / 已升级 / 终身 Pro 四种状态展示；登录后有付款记录和账号用量 | 公开 | `GET /plans/trip-pro`；登录后账户概览、`GET /payments`、`GET /users/me/usage` |
| `/credits` | 图片来源与授权（CC 署名） | 公开 | `constants/place-images.generated.json` |
| `/s/[token]` | 别人分享的旅行成果（只读） | 令牌 | `GET /share/{token}` |
| `/health` | 部署健康检查（返回 `{"status":"ok"}`） | 公开 | — |

## 登录后页面

| 路径 | 页面目的 | 主要数据来源 |
|---|---|---|
| `/trips` | 我的旅行列表、继续进行 | 旅行列表、每段旅行的总结（N+1，见技术债）、当前旅行行程 |
| `/trips/new` | 创建旅行（目的地搜索、加入官方探索、FREE 名额提示） | 账户概览、目的地搜索、`POST /trips` |
| `/trips/[id]` | **已下线**，308 到 `/trips/[id]/map` | — |
| `/trips/[id]/map` | 进入旅行的默认页。地图工作台：地点、行程、打卡、时间轴；「旅行操作」菜单（编辑、完成、归档、删除） | 旅行、地点、行程、时间轴、地点 / 目的地搜索 |
| `/trips/[id]/gallery` | 照片墙：分页、筛选、精选、封面、批量、关联打卡 | 照片分页、打卡 |
| `/trips/[id]/photos` | 兼容旧链接，重定向到 `/gallery` | — |
| `/trips/[id]/achievements` | **已下线**，308 到 `/trips/[id]/map` | — |
| `/trips/[id]/summary` | **已下线**，308 到 `/trips/[id]/map` | — |
| `/trips/[id]/share` | 分享成果：城市海报 / 九宫格 / 每日长图导出，分享链接管理；支持 `?mode=` 直接打开某种成果 | 旅行、总结、时间轴、照片、行程、分享链接、方案配置 |
| `/trips/[id]/video` | Travel Story 工作台：模板、照片、配乐（我的音乐或无音乐）、分镜预览、生成与进度、我的视频 | 视频项目、模板、照片、打卡、方案配置、我的音乐 |
| `/memories` | 旅行回忆 | `GET /me/memories`、`/me/memories/trips` |
| `/profile` | 设置中心，`?tab=` 选栏目：profile（个人资料）、旅行偏好、隐私与分享、通知、security（账户与安全）、Trip Pro | 用户、账户概览、会话、头像上传等 |

## 外壳

- 侧栏入口（11-08 起）：首页、我的旅行、推荐探索、旅行回忆；设置；升级入口。旅行内的入口（地图、照片、分享、视频）随「当前旅行」显示，见 [工作台改版验收](../08_testing/07_旅行工作台改版验收_2026-11-08.md)。
- 桌面：左侧导航（`AppSidebar`）+ 顶栏（搜索 Ctrl/Cmd+K、通知、快速打卡、头像）+ 工作区；页面内容用 `PageContainer` 居中。
- 手机：单栏 + 底部导航（`components/mobile/`），快速打卡是底部弹层。
- 旅行子页面共用旅行内导航（`components/trip/LiveTripSubnav.tsx`，地图、照片、分享、视频四项），打开任一子页面会更新「最近打开的旅行」。
