# 需求规格说明

来源：原《MVP 计划书 v3.0》（09-15）、《旅行视频输出功能计划 v1.0》（已删除，可从 Git `c6adb8d` 找回），并按 2026-10-13 的代码与用户已做的决定修正。
「状态」列只说明是否已实现，验证情况见 [项目长期记忆](../99_management/01_项目长期记忆.md)。

## 1. 产品目标

MVP 验证四件事：
1. 用户是否愿意创建旅行并持续记录行程与打卡；
2. 用户是否愿意上传照片、写记录并形成时间轴；
3. 用户是否愿意生成并分享旅行成果；
4. 用户是否愿意为更完整的成果（高清、视频、更多额度）付费。

首阶段市场：简体中文 + 东京自由行游客；产品底层从第一版就支持全球目的地。

## 3. 套餐与权益（以代码为准）

具体数值是后端常量，经 `GET /api/v1/plans/trip-pro` 下发，规则细节见 [用例与业务规则](../02_business/03_用例与业务规则.md)。

| 项目 | FREE 旅行 | Trip Pro 旅行 |
|---|---|---|
| 同时保留的 FREE 旅行数 | 1 个（归档的不算） | 不占 FREE 名额 |
| 每段旅行的打卡 / 照片 | 各 10 个 / 10 张 | 不限 |
| 分享图 | 标准清晰度 + 水印 | 高清、无水印 |
| Travel Story | 720p、15/30 秒、最多 10 张、带水印、只能用 FREE 模板和音乐 | 1080p、15/30/60 秒、最多 30 张、全部模板和音乐 |
| 价格 | — | ¥4 / 段旅行（一次性，不续费不过期） |

终身 Pro（¥1000 买断）：账号下现有和以后新建的旅行都是 PRO，并开通账号会员（目前会员只用于「我的音乐」）。

⚠ 原 MVP 计划书价格为 ¥490 / 段旅行；当前 ¥4 是用户在第二阶段审计时定的价格，二者冲突 **❓ 待用户确认**（见 ADR-008）。

## 4. 非功能需求

| 类别 | 要求 | 状态 |
|---|---|---|
| 时区 | 事件时间按 UTC 存；按用户或打卡时区展示；旅行日期用 DATE | 已实现 |
| 隐私 | 旅行默认 PRIVATE；分享页默认坐标粗化；凭证不进 localStorage | 已实现 |
| 安全 | 所有私人数据按当前用户做归属校验；登录与验证码限流；生产拒绝弱密钥 | 已实现 |
| 响应式 | 手机（360–430）、平板（768）、桌面到 3440 宽都无横向溢出 | 已实现（E2E mobile-layout 覆盖 360–1440） |
| 图片 | 大屏不糊、手机不浪费流量（多档尺寸 + srcset） | 已实现 |
| 可用性 | 视频渲染失败可重试；音乐不可用时降级为无音乐 | 已实现 |
| 可部署 | 配置全部走环境变量；生产缺少必要变量时拒绝启动 | 已实现，**未在真实环境部署过** |
| 合规 | 第三方图片 / 音乐授权可追溯并署名；地图与天气服务符合条款 | 图片、音乐已实现；地图底图、天气、逆地理 **未达标**（P1） |

## 5. 范围外（MVP 明确不做）

实时位置共享、聊天、好友、社交动态流、公开内容社区、AI 行程规划、酒店 / 餐厅预订、大规模官方城市内容、原生 App、GPS 强制验证、复杂防作弊、专业视频剪辑（自由时间轴、滤镜、多轨音频、AI 剪辑配音、4K）、商家后台、微服务基础设施。

## 6. 未来考虑

- 更多官方城市（代码里探索度目前写死东京，见技术债）
- 会员订阅（月度 / 年度，数据模型已支持到期时间）
- 修改邮箱、自定义地点编辑、照片标题
- 视频 1:1 比例（目前支持 9:16、4:5、16:9）
