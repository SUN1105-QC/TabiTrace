## 项目概况

旅迹 TabiTrace：旅行打卡、记录与纪念平台（地点 + 行程 + 打卡 + 照片 + 地图 + 分享图 + 打卡记录导出 + Travel Story 视频）。Next.js 16.4.5 前端 + Spring Boot 4 API + MySQL 8.4 + FFmpeg 视频 Worker，部署在 SUNOWS AWS Lightsail（Docker Compose + 主机 Nginx）。详见 [项目总说明](../00_overview/00_项目总说明.md)。

正式网址：https://tabi.sunows.com

## 产品形态要点（容易和旧文档混淆）

- 全局导航只有：首页、我的旅行、推荐探索、旅行回忆（另有设置、升级入口）。旅行内显示当前旅行与切换入口，子页面是地图与打卡、照片、分享成果、旅行视频。
- 首页是任务式工作台（当前旅行、记录这一刻、下一站、最近活动）；地图、照片、导出、视频和快速打卡都跟随「当前旅行」；归档旅行只读。
- 地图页可以导出打卡记录：整趟或按日，PDF / PNG / JPG / CSV，PDF 和图片默认带旅行地图页，全部在浏览器生成，不经过后端。
- 九宫格第 1、5、9 格也是照片位，最多 9 张，不足保留空位。
- 配乐只有「我的音乐」（需要会员，目前只有终身 Pro 开通）或无音乐。
- 操作主色是 `#B54C1E`。

## 本机工作注意（给 AI）
- 用户要求所有回复用简体中文；Git 只在用户明确同意后提交推送。
- 发布时以服务器**实际运行的版本**为基线，只替换本次相关文件，记录文件哈希到 `RELEASE_MANIFEST.json`；能只换 Web 就不动 API / Worker / MySQL。
- 对公网只做只读检查（`public-smoke` 和 `e2e/tools/check-*.mjs`，业务数据只注入浏览器），不要创建账号、发信或付款。
- 开发服务器运行时执行 `npm run build` 可能影响 `next dev`，构建后如页面异常就重启 3000 端口服务。
- 从工具里启动的服务会随工具作业退出，用 WMI 调用 `启动TabiTrace前后端.bat`。
- 3000 / 8080 可能被用户其他项目占用，结束前必须先问；可改用 3001 / 8081。
- E2E 测试数据按本次新建的 id 清理，不要按邮箱前缀批量删除。
- 本机 Git stash 有两份 10-26 的旧备份，不要直接 pop。
