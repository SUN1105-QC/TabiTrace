## 项目概况

旅迹 TabiTrace：旅行打卡、记录与纪念平台（地点 + 行程 + 打卡 + 照片 + 地图 + 成就 + 分享图 + Travel Story 视频）。Next.js 16 前端 + Spring Boot 4 API + MySQL + FFmpeg 视频 Worker；目标部署 Railway。详见 [项目总说明](../00_overview/00_项目总说明.md)。

## 本机工作注意（给 AI）
- 用户要求所有回复用简体中文；Git 只在用户明确同意后提交推送。
- `npm run build` 会弄坏正在运行的 `next dev`（共用 `.next`），构建后重启 3000 端口服务。
- 从工具里启动的服务会随工具作业退出，用 WMI 调用 `启动TabiTrace前后端.bat`。
- 3000 / 8080 可能被用户其他项目占用，结束前必须先问；可改用 3001 / 8081。
- E2E 测试数据按本次新建的 id 清理，不要按邮箱前缀批量删除。
