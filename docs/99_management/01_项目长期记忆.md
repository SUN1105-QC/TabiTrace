## 项目概况

旅迹 TabiTrace：旅行打卡、记录与纪念平台（地点 + 行程 + 打卡 + 照片 + 地图 + 分享图 + 打卡记录导出 + Travel Story 视频）。Next.js 16.4.5 前端 + Spring Boot 4 API + MySQL 8.4 + FFmpeg 视频 Worker，部署在 SUNOWS AWS Lightsail（Docker Compose + 主机 Nginx）。详见 [项目总说明](../00_overview/00_项目总说明.md)。

正式网址：https://tabi.sunows.com

## 产品形态要点（容易和旧文档混淆）

- 全局导航只有：首页、我的旅行、推荐探索、旅行回忆（另有设置、升级入口）。旅行内显示当前旅行与切换入口，子页面是地图与打卡、照片、分享成果、旅行视频。
- 首页是任务式工作台（11-12 按用户设计图改版）：问候标题随旅行状态变化，旅行横幅带城市线描插画（巴黎是铁塔，其他城市是通用剪影），四个带说明的快捷入口，日期卡式「下一站」，图标式最近活动。地图、照片、导出、视频和快速打卡都跟随「当前旅行」；归档旅行只读。
- 成品图（九宫格、长图、海报、手帐）在浏览器里用 html-to-image 导出：照片先缩到导出所需像素再内嵌，Safari / iOS 先预绘一次，iOS 上长图按画布面积上限降倍率（`utils/share-export.ts`）。
- iOS 上 viewport 追加 `maximum-scale=1`（根布局内联脚本），输入框聚焦不再自动放大；安卓不加。
- 地图页可以导出打卡记录：整趟或按日，PDF / PNG / JPG / CSV，PDF 和图片默认带旅行地图页，全部在浏览器生成，不经过后端。
- 九宫格第 1、5、9 格也是照片位，最多 9 张，不足保留空位。
- 配乐只有「我的音乐」（需要会员，目前只有终身 Pro 开通）或无音乐。
- 操作主色是 `#B54C1E`（11-13 起视频、回忆、探索、落地页与 Tailwind `warm` 也统一为它）。
- 推荐探索与定价页访客也能看：已登录用工作区外壳，未登录用公开导航（`SiteHeader` 的 `PUBLIC_APP_PREFIXES`）。

## 本机工作注意（给 AI）
- 用户要求所有回复用简体中文；Git 只在用户明确同意后提交推送。
- 发布从推送后 CI 通过的提交 `git archive` 打包，`RELEASE_MANIFEST.json` 记提交与包的 SHA256；能只换 Web 就不动 API / Worker / MySQL（参照 `releases/deploy-fix-build.sh` / `deploy-fix-switch.sh`：只构建 Web，切换前给运行中的 API / Worker 镜像打新标签）。本机没有 `gh`，CI 状态用 GitHub 公开 API（`api.github.com/repos/SUN1105-QC/TabiTrace/actions/runs`）查询。
- 全页面审查：`AUDIT_WEB=http://localhost:3000 node e2e/tools/audit-all-pages.mjs`（四种尺寸逐屏截图 + 指标，输出 `backend/.tabitrace/page-audit/`），截图需要人工逐页看。
- 验证导出类问题：`e2e/fixtures/layout-ui.mjs` 只在浏览器注入测试数据；要模拟正式环境的跨域大图，另开一个带 CORS 头的本地图片服务，并把 fixture 里照片的 `imageUrl` / `mediumUrl` 换掉。检查长页面要按视口逐屏截图，整页截图会改变 vh。
- 对公网只做只读检查（`public-smoke` 和 `e2e/tools/check-*.mjs`，业务数据只注入浏览器），不要创建账号、发信或付款。
- 开发服务器运行时执行 `npm run build` 可能影响 `next dev`，构建后如页面异常就重启 3000 端口服务。
- 从工具里启动的服务会随工具作业退出，用 WMI 调用 `启动TabiTrace前后端.bat`。
- 3000 / 8080 可能被用户其他项目占用，结束前必须先问；可改用 3001 / 8081。
- E2E 测试数据按本次新建的 id 清理，不要按邮箱前缀批量删除。
- 本机 Git stash 有两份 10-26 的旧备份，不要直接 pop。
