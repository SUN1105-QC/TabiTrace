# 项目总说明

## 项目

| 项目 | 内容 |
|---|---|
| 名称 | 旅迹 TabiTrace |
| 一句话 | 把你去过的地方，变成值得回看的旅行作品 |
| 定位 | 面向旅行者的旅行打卡、记录与纪念平台：把「地点 + 行程 + 打卡 + 时间 + 照片 + 文字 + 地图 + 成就 + 视频」整理成可以长期保存、回看和分享的个人旅行作品 |
| 解决的问题 | 旅行记录散落在相册、地图、社交软件里；旅行结束后得不到一份完整的纪念成果 |
| 主要用户 | 20～40 岁、有自由行和拍照分享习惯的简体中文用户；第一阶段重点是东京自由行游客 |
| 产品边界 | 全球任意目的地都能记录（通用底座）+ 官方城市探索内容（首套为东京）。不是东京限定产品 |
| 商业模式 | 免费体验 + 按旅行购买 Trip Pro + 买断「终身 Pro」（详见 [需求规格](../01_requirements/01_需求规格说明.md)） |

## 核心场景

1. **行前**：创建旅行 → 选目的地（东京可加入官方探索）→ 规划行程、收藏地点
2. **旅途中**：手机快速打卡（定位、天气、照片一次保存）、上传照片、写下当时的文字
3. **旅行后**：看地图、时间轴、统计和成就 → 标记完成
4. **成果**：生成城市海报、九宫格、每日长图、Travel Story 视频 → 下载或通过非公开链接分享
5. **回看**：在「旅行回忆」里按时间回顾

## 系统组成（一句话版）

Next.js 网页 → Spring Boot REST API → MySQL；照片 / 成片存对象存储（Cloudflare R2）；Travel Story 由独立的视频 Worker 用 FFmpeg 生成；目标部署平台 Railway。
完整说明见 [系统总体设计](01_系统总体设计.md)。
