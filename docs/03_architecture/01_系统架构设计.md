# 系统架构设计

系统整体组成和业务链路见 [系统总体设计](../00_overview/01_系统总体设计.md)；本文讲组件边界、网络关系和关键数据流。部署拓扑见 [部署架构设计](03_部署架构设计.md)。

## 1. 组件与边界

| 组件 | 代码 | 运行形态 | 职责边界 |
|---|---|---|---|
| Web | `frontend/` | Next.js（开发 `next dev`，生产 standalone 容器，默认 Webpack 构建） | 页面渲染、交互、分享图合成；**不直接访问数据库或存储密钥** |
| API | `backend/api/` | Spring Boot（端口 8080，前缀 `/api/v1`） | 唯一的业务入口：认证、规则、归属校验、预签名、支付、定时任务；启动时执行 Flyway 迁移 |
| 视频 Worker | `backend/video-worker/` | Spring Boot（**没有 HTTP 端口**） | 渲染：轮询队列、下载素材、合成 MP4、上传、回写状态；消费成片清理任务；不执行迁移 |
| MySQL | — | MySQL 8 | 全部业务数据；同时充当视频任务队列和限流计数表 |
| 对象存储 | — | Cloudflare R2（生产）/ 本地磁盘（开发） | 照片、头像、自定义音乐、成片；历史曲库音频仍在桶里，产品不再使用 |

服务端**没有缓存层**（没有 Redis、没有 `@Cacheable`），也没有消息队列。前端有两处短时内存缓存：当前用户信息（5 秒内合并重复请求）和开发数据源切换时需要清空的数据缓存（`services/api.ts` 的 `registerDataCache`）。

## 2. 网络关系

```
开发：浏览器 ──▶ localhost:3000（Next.js）
      浏览器 ──▶ localhost:8080/api/v1（跨域，CORS 允许 3000）
      浏览器 ──▶ localhost:8080/api/v1/local-storage/*（带签名的本地上传 / 读取）

生产：浏览器 ──HTTPS──▶ 主机 Nginx（80 / 443）
        ├─ /api/v1/* ──▶ 127.0.0.1:18080（api 容器）
        └─ 其他       ──▶ 127.0.0.1:13000（web 容器）
      api、worker ──Compose 内网──▶ mysql（不映射主机端口）
      浏览器 ──HTTPS──▶ media.sunows.com（R2 公开桶）/ R2 预签名地址（上传）
      worker ──▶ R2（媒体桶、私有音乐桶）
      api ──▶ Stripe（未配置）/ SMTP 或 Resend / Nominatim / Open-Meteo
      Stripe ──Webhook──▶ tabi.sunows.com/api/v1/payments/stripe/webhook ──▶ api
```

生产由主机 Nginx 统一入口（ADR-016）：浏览器只访问同源 `/api/v1`，refresh Cookie 是第一方 Cookie，不需要跨域。Web 镜像里也配置了 `API_INTERNAL_URL=http://api:8080` 的 rewrites，但公网的 `/api/v1/*` 请求由 Nginx 直接转给 API，不经过 Web。客户端 IP：生产 `TRUST_PROXY_HEADERS=true`，取 Nginx 写入的 `X-Forwarded-For`（11-07 起，见安全设计）。

## 3. 关键数据流

| 流程 | 说明 | 详细设计 |
|---|---|---|
| 认证 | 访问令牌在内存，401 时用 HttpOnly Cookie 刷新并重放请求 | [认证设计](../07_security/01_认证设计.md) |
| 上传 | 预签名 → 浏览器直传存储 → 登记元数据 | [文件存储设计](../06_backend/04_文件存储设计.md) |
| 视频 | API 冻结分镜入队 → Worker 渲染 → 回写状态，前端轮询进度 | [任务与视频渲染机制](../06_backend/05_任务与视频渲染机制.md) |
| 分享图 | 浏览器读取数据和照片，按方案配置的规格合成 PNG | [前端架构](../05_frontend/01_前端架构设计.md) |
| 支付 | Checkout → Webhook → 升级 | [业务流程](../02_business/01_业务流程设计.md) §7 |
| 公开分享 | 匿名访问 `/share/{token}`，只返回公开字段 | [权限设计](../07_security/02_权限设计.md) |

## 4. 外部服务

| 服务 | 调用方 | 用途 | 生产状态 |
|---|---|---|---|
| Cloudflare R2 | API、Worker、浏览器 | 存储 | 已接入（10-27）：`tabi-media`、`tabi-music-private`、`media.sunows.com` |
| Stripe | API（REST）、Stripe → API（Webhook） | 付款 | 未配置，`paymentsAvailable=false` |
| Resend / SMTP | API | 验证码邮件 | 生产用 Gmail SMTP，认证通过（10-27），收件箱送达待用户验收 |
| Nominatim | API `geo` | 逆地理编码 | 条款不适合商用 |
| Open-Meteo | API `geo` | 天气快照 | 免费层禁止商用 |
| 地图底图 | 浏览器 | 地图样式 | 生产用 OpenFreeMap Liberty（`NEXT_PUBLIC_MAP_STYLE_URL`）；开发回退 OSM 官方瓦片，生产禁止 |

## 5. 前端与后端的契约

- 统一前缀 `/api/v1`；JSON；统一信封 `ApiResponse { success, data, code, message }`。
- 前端所有请求经过 `frontend/services/api.ts`，业务接口集中在 `services/tabitrace-api.ts`（类型与后端 DTO 同名同字段）。
- 套餐数值、价格、视频规格由 `GET /plans/trip-pro` 下发，前端不另写一份。
- 没有 OpenAPI 描述文件；接口清单维护在 [API 接口设计](../06_backend/02_API接口设计.md)。
