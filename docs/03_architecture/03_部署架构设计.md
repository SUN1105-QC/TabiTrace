# 部署架构设计

已上线：https://tabi.sunows.com（AWS Lightsail，175.41.217.207）。部署操作见 [Lightsail 指南](../../deploy/lightsail/README.md)，实际发布情况见 [发布记录](../09_deployment/04_Lightsail发布记录.md)。

## 生产（Lightsail，当前）

```
用户
 │ HTTPS（Let's Encrypt，certbot 自动续期，续期后重载 Nginx）
 ▼
主机 Nginx（80 → 301，443；client_max_body_size 32m）
 ├─ /api/v1/* ──▶ 127.0.0.1:18080 ──▶ api 容器（Spring Boot，prod，启动时 Flyway，/actuator/health，内存上限 1g）
 └─ 其他      ──▶ 127.0.0.1:13000 ──▶ web 容器（Next.js standalone，/health，768m）

Compose 内网（项目名 tabi，compose.production.yml）：
 api、worker ──▶ mysql（MySQL 8.4，不映射主机端口，数据目录 /srv/sunows/data/mysql/tabi，1g）
 worker（FFmpeg + 中文字体，无端口，2g）

外部：Cloudflare R2（tabi-media 公开，media.sunows.com；tabi-music-private 私有）· Gmail SMTP · OpenFreeMap · Stripe（未配置）
```

- 目录：服务器配置 `/srv/sunows/apps/tabi/shared/.env`（0600，不进 Git）；备份 `shared/backups/`；发布源码 `releases/<标签>/`，当前版本指针 `shared/current-release.txt`。
- 发布：`deploy/lightsail/deploy.sh` 校验环境 → 构建三个镜像 → 备份正在运行的数据库 → `up --wait` → 健康检查。迁移由 API 启动时执行。
- 回退：旧镜像保留；数据库迁移不随代码回退，升级前有快照，禁止 `down -v`。
- 日志：Docker json-file，每容器 3 × 10MB。
- GitHub 推送不会自动发布。

## 历史方案（Railway，未使用）

```
用户
 │ HTTPS
 ▼
web（Next.js，frontend/，Railpack 构建）            ← 唯一对公网开放的服务，健康检查 /health
 │ 私网 http://api.railway.internal:PORT/api/v1/*（rewrites，构建时生成）
 ▼
api（Spring Boot，backend/api/Dockerfile）          ← 不开放公网；启动时 Flyway 迁移；健康检查 /actuator/health
 │ 私网
 ▼
MySQL（Railway 模板，建议 mysql:8.4）              ← 不开放 TCP Proxy（管理时临时开启）
 ▲
 │ 私网
worker（backend/video-worker/Dockerfile，含 FFmpeg 与中文字体）← 无端口，restart ALWAYS

外部：Cloudflare R2（公开桶：照片、头像、成片、试听；建议私有桶：音乐原曲、我的音乐）
      Resend 或 SMTP · Stripe · 地图底图服务商
```

- 所有服务与 MySQL 在同一 Region（建议 Singapore）。
- 停机：api 收到 SIGTERM 后最多等 20 秒处理完请求（`drainingSeconds` 30）；worker 不再领取任务，当前视频最多再等 20 秒，否则中断并放回队列（`drainingSeconds` 35）。
- 迁移失败 → api 启动失败 → 健康检查不通过 → 部署失败，旧版本继续服务。

## 本地开发

```
浏览器 ─▶ next dev :3000
浏览器 ─▶ Spring Boot :8080 ─▶ MySQL :3306（本机）
                          └─▶ 本地磁盘 backend/api/.tabitrace/uploads
video-worker（有 FFmpeg 时启动）─▶ MySQL；成片写到 frontend/public/generated-videos
开发邮件接收器 :1025（SMTP）/ :1080（查看）
```
由根目录 `启动TabiTrace前后端.bat` 一键拉起；启动方式与注意事项见 [新手上手指南](../09_deployment/03_新手上手指南.md)。
