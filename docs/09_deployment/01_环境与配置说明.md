# 环境与配置说明

**禁止在文档、代码、仓库里写真实密钥。** 示例文件：`backend/.env.example`、`frontend/.env.local.example`（只有变量名和占位值）。

## 1. 环境

| 环境 | 现状 | 说明 |
|---|---|---|
| Local | 在用 | 开发者本机：Windows 11、Node v25.1.0（要求 ≥20.9）、Java 21.0.4、Maven 3.9.16、MySQL 8.0.46、FFmpeg（winget 或 `.tools/ffmpeg`）。2026-10-13 实测 |
| Development / Testing / Staging | **没有** | 计划在 Railway 建测试环境（见开发执行计划的下一阶段） |
| Production | **没有部署过** | 目标 Railway，见 [部署设计](02_部署设计.md) |

## 2. Spring profile

| profile | 激活 | 固定行为 |
|---|---|---|
| `local`（默认） | `SPRING_PROFILES_ACTIVE=local` 或不设置 | `com.tabitrace` 日志 DEBUG；默认开启 Mock 渲染器；存储、支付默认 local / mock；注册开发用音乐版权后台接口 |
| `prod` | Dockerfile 里写死 | `STORAGE_MODE=r2`、`PAYMENTS_MODE=stripe`、Mock 渲染器关闭、refresh Cookie Secure、健康检查不展示细节；启动时校验必要变量，缺失或是开发默认值就拒绝启动 |

## 3. 环境变量

### API（`backend/api`）
| 变量 | 用途 | 本地默认 / 示例 |
|---|---|---|
| `SPRING_PROFILES_ACTIVE` | local / prod | local |
| `PORT` / `SERVER_PORT` | 监听端口（Railway 注入 `PORT`） | 8080 |
| `DB_URL`、`DB_USERNAME`、`DB_PASSWORD`、`DB_POOL_SIZE` | 数据库（不要把密码写进 URL） | 本机 `tabitrace` 库、`tabitrace_app` 账号 |
| `JWT_SECRET` | 令牌签名，至少 32 字节随机值 | 开发默认含 `change-me`（prod 拒绝） |
| `AUTH_COOKIE_SECURE` | refresh Cookie 是否 Secure | false（prod 固定 true） |
| `TRUST_PROXY_HEADERS` | API 只能经可信代理访问时设 true，按 `X-Forwarded-For` 最右侧取 IP | false |
| `APP_PUBLIC_URL`、`APP_API_URL` | 正式站点地址（邮件、分享链接、支付回跳）、API 地址 | localhost:3000 / 8080 |
| `CORS_ALLOWED_ORIGINS` | 允许的来源（prod 拒绝 `*` 和 localhost） | localhost:3000、127.0.0.1:3000 |
| `STORAGE_MODE`、`LOCAL_STORAGE_DIR` | local / r2；本地目录 | local、`./.tabitrace/uploads` |
| `R2_ENDPOINT`、`R2_ACCESS_KEY`、`R2_SECRET_KEY`、`R2_BUCKET`、`R2_PUBLIC_BASE_URL` | 对象存储 | — |
| `PAYMENTS_MODE`、`STRIPE_SECRET_KEY`、`STRIPE_WEBHOOK_SECRET` | 支付（mock 仅限开发） | mock |
| `MAIL_PROVIDER`、`RESEND_API_KEY`、`MAIL_HOST`、`MAIL_PORT`、`MAIL_USERNAME`、`MAIL_PASSWORD`、`MAIL_SMTP_AUTH`、`MAIL_SMTP_STARTTLS`、`MAIL_SMTP_SSL`、`MAIL_FROM_ADDRESS`、`MAIL_FROM_NAME` | 邮件（smtp 或 resend） | smtp → localhost:1025 |
| `VIDEO_MOCK_RENDERER`、`VIDEO_PROCESSING_TIMEOUT_SECONDS` | Mock 渲染器开关、心跳超时 | true、300 |
| `USER_MUSIC_MAX_FILE_BYTES`、`USER_MUSIC_MAX_TRACKS`、`USER_MUSIC_MAX_TOTAL_BYTES` | 我的音乐限制 | 30MB、20、500MB |

### Worker（`backend/video-worker`）
| 变量 | 用途 | 本地默认 |
|---|---|---|
| `DB_URL`、`DB_USERNAME`、`DB_PASSWORD` | 同 API | 同 API |
| `STORAGE_MODE` | local / r2（**不设置时是 mock**；prod 固定 r2） | mock |
| `R2_*`、`R2_MUSIC_BUCKET` | 存储；原曲所在私有桶（不填用 `R2_BUCKET`） | — |
| `FFMPEG_BINARY` | FFmpeg 路径 | `ffmpeg` |
| `VIDEO_WORK_DIR`、`VIDEO_PUBLIC_BASE_URL` | 工作目录 / 本地成片访问地址 | `../../frontend/public/generated-videos`、`http://localhost:3000/generated-videos` |
| `VIDEO_MUSIC_DIR`、`WORKER_MUSIC_CACHE_DIR` | 本地曲库目录 / 生产从 R2 下载的缓存目录 | `../api/.tabitrace/uploads`、系统临时目录 |
| `VIDEO_WORKER_POLL_MS`、`WORKER_SHUTDOWN_GRACE_SECONDS`、`WORKER_FFMPEG_TIMEOUT_SECONDS`、`WORKER_HEARTBEAT_SECONDS` | 轮询、停机宽限、FFmpeg 超时、心跳 | 5000、20、600、15 |

### Web（`frontend`）
| 变量 | 用途 | 说明 |
|---|---|---|
| `API_INTERNAL_URL` | 生产：私网 API 地址，Next.js rewrites 转发 | **构建阶段就要有** |
| `APP_URL` | 正式站点地址（canonical、OpenGraph） | 生产构建与启动必填，必须 https、不能是本机地址，否则构建失败 |
| `NEXT_PUBLIC_API_BASE_URL` | 浏览器访问 API 的地址 | 开发可选；生产留空（同源 `/api/v1`） |
| `NEXT_PUBLIC_MAP_STYLE_URL` / `NEXT_PUBLIC_MAP_TILE_URL` | 地图底图（矢量样式 / 栅格瓦片） | 生产必须配置一项，否则地图只有标点 |
| `NEXT_PUBLIC_MAP_ATTRIBUTION`、`NEXT_PUBLIC_MAP_API_KEY` | 底图署名；替换地址里的 `{key}`（只能用限制了域名的公开 key） | `NEXT_PUBLIC_*` 会打进浏览器代码 |

### E2E
`E2E_WEB`、`E2E_API`、`E2E_EMAIL`、`E2E_PASSWORD`、`E2E_TRIP_ID`、`E2E_MAILBOX_URL`、`E2E_BROWSER`、`E2E_REPORT_DIR`（见 `e2e/README.md`）。

## 4. 本机端口与注意事项

| 端口 | 服务 |
|---|---|
| 3000 | Web（`next dev`） |
| 8080 | API |
| 3306 | MySQL |
| 1025 / 1080 | 开发邮件接收器（SMTP / 查看页） |

- 3000 / 8080 可能被开发者本机的其他项目占用：不要直接结束别人的进程；可以把整套服务改到 3001 / 8081（只改环境变量：`SERVER_PORT`、`APP_API_URL`、`APP_PUBLIC_URL`、`CORS_ALLOWED_ORIGINS`、`NEXT_PUBLIC_API_BASE_URL`，前端 `npm run dev -- -p 3001`，E2E 用 `E2E_WEB` / `E2E_API`）。
- 本地 MySQL 自动 TLS 协商有问题，启动脚本使用 `sslMode=DISABLED&allowPublicKeyRetrieval=true`（只连 127.0.0.1）。
