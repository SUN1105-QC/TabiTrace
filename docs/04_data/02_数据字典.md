# 数据字典

记录**业务语义**：这个数据在业务上是什么意思、容易误解的地方在哪。列类型和约束以迁移文件为准，状态取值的完整清单见 [枚举与常量](03_枚举与常量定义.md)。

## 1. 跨层命名约定（代替单独的字段映射表）

| 层 | 命名 | 例子 |
|---|---|---|
| 数据库 | snake_case | `destination_name` |
| 后端 Entity / DTO | camelCase（MyBatis `map-underscore-to-camel-case: true` 自动映射） | `destinationName` |
| API JSON | 与 DTO 字段同名（Jackson，空值不输出 `non_null`） | `destinationName` |
| 前端类型 | 与 API 同名（`services/tabitrace-api.ts`） | `destinationName` |

**命名不对应的例外**（改字段时要特别注意）：

| 数据库 | API / 前端 | 说明 |
|---|---|---|
| `photos.is_featured` | `featured` | 是否精选 |
| `checkins.place_name_snapshot` / `area_snapshot` | `placeName` / `area` | 打卡时的地点名称快照 |
| `checkins.location_accuracy_m` | 请求里是 `accuracyM` | 定位精度（米） |
| `share_links.share_token` | `token`，另外 API 拼出 `url` | 分享令牌 |
| `photos.thumb_key / medium_key` | 登记时请求叫 `thumbKey / mediumKey`，返回 `thumbUrl / mediumUrl` | 两档尺寸 |
| `video_projects.template_code / music_code` | `templateCode / musicCode` | 一致，列出来是因为 `musicCode=null` 有业务含义（无音乐） |
| `refresh_tokens.jti` | 不出现在 API；会话列表用 `id` | refresh token 的唯一标识 |

## 2. 核心业务对象

### 用户 `users`
| 字段 | 含义 |
|---|---|
| `status` | ACTIVE：正常；DELETION_PENDING：已申请注销、在 7 天冷静期 |
| `timezone` | 用户时区，展示时间轴、统计按天分组都用它；注册时取浏览器时区，没有则 `Asia/Tokyo` |
| `locale` | 界面语言 zh-CN / en-US / ja-JP |
| `default_visibility` | ⚠ 列存在但目前不生效：新旅行一律 PRIVATE |
| `share_exact_location` | 分享页是否返回精确坐标（默认否，粗化到约 1 公里） |
| `share_link_expiry_days` | 新建分享链接的默认有效期：0 = 长期，7，30 |
| `lifetime_pro_at` | 买断终身 Pro 的时间；不为空表示账号下所有旅行都是 PRO |
| `avatar_url` / `avatar_small_url` | 512 头像与 160 小图（导航栏用小图，旧头像没有小图时回退） |

### 旅行 `trips`
| 字段 | 含义 |
|---|---|
| `plan_type` | 这段旅行的权益：FREE / PRO。**权益按旅行，不按用户**（终身 Pro 是把所有旅行都设为 PRO） |
| `status` | PLANNING：还没打卡；ONGOING：已经开始打卡；COMPLETED：用户标记完成或取消归档；ARCHIVED：只读、不占 FREE 名额 |
| `visibility` | PRIVATE：只有本人；UNLISTED：存在有效分享链接，持链接可看 |
| `destination_name` / `city` / `country_code` | 目的地显示名、城市、国家；匹配官方城市时先看 `city` 再看 `destination_name` |
| `cover_image` | 封面地址（可以是用户照片或官方图） |

### 地点 `places`
| 字段 | 含义 |
|---|---|
| `source_type` | OFFICIAL：官方地点（迁移写入，只读）；CUSTOM：用户在某段旅行里创建 |
| `city` | 城市名（中文，如「东京」），官方地点按它归属官方城市 |
| `tagline` / `recommend_reason` / `stay_minutes` / `best_time` / `tags` / `editor_rank` | 推荐探索用的编辑内容（只有官方地点有） |
| `cover_image` | 官方地点保存 1280 档高清图地址，前端按显示宽度换档；没有可信照片时为 NULL，前端显示文字封面 |

### 打卡 `checkins`
| 字段 | 含义 |
|---|---|
| `checkin_type` | 打卡方式（目前写入 MANUAL） |
| `checkin_time` | 打卡时刻（UTC） |
| `timezone` | 打卡时设备所在时区；判断「打卡日期是否在旅行内」时优先用它 |
| `place_id` | 关联地点，可以为空（随手打卡） |
| `itinerary_item_id` | 由行程转来时的行程 id |
| `weather_*` | 打卡时刻的天气快照（拿不到就为空，不猜测） |

### 照片 `photos`
| 字段 | 含义 |
|---|---|
| `storage_key` | 原图在存储里的路径；`image_url` 原图地址（只用于下载和视频生成） |
| `thumb_*` / `medium_*` | 浏览器生成的缩略图（640 框）与中图（1600 框）；旧照片没有，显示时回退原图 |
| `captured_at` | 拍摄时间；统计按天分组时优先用它，没有则用 `created_at` |
| `checkin_id` | 关联的打卡（打卡删除后置空） |

### 视频项目 `video_projects`
| 字段 | 含义 |
|---|---|
| `status` / `progress` / `render_stage` | 生成状态、进度百分比、当前阶段 |
| `settings_json` | 用户在工作台的全部设置（开关、音量等） |
| `storyboard_json` | 开始生成时冻结的分镜（含音乐片段），Worker 只按它渲染 |
| `music_code` / `music_source` / `user_music_id` | 曲库音乐 code；来源 SYSTEM（曲库）/ USER（我的音乐）/ NONE（无音乐）；用户音乐 id |
| `renderer` | FFMPEG：真实 Worker；MOCK：开发环境假渲染器（地址不可播放） |
| `error_code` / `error_message` / `render_warning` | 失败原因；成功但有提示（如音乐降级） |

### 成本观测（V21）

| 字段 / 表 | 含义 |
|---|---|
| `render_usage_daily` | scope + UTC 统计日唯一，保存已入队请求数及目标成片秒数；删除视频项目不清除当日用量 |
| `cost_control_locks` | 持久化全站提交锁，覆盖排队数量检查和用量预留 |
| `cost_alerts` | scope + UTC 日期 + 资源类别唯一，告警只记一次；不存密码或支付密钥 |
| `video_projects.output_bytes` | Worker 成片实际字节数；旧文件为 NULL，不冒充已计量的零字节 |

### 成片清理 `video_output_deletions`（V22）

| 字段 | 含义 |
|---|---|
| `project_id` | 已删除视频项目编号，主键保证每个项目只有一个清理任务 |
| `user_id` / `trip_id` | 删除前的归属快照，仅用于推导该项目的标准成片路径；不设置外键，避免级联清除任务 |
| `attempts` / `next_attempt_at` / `last_error` | 失败次数、下次重试时间和异常类名；不存签名 URL、密钥或完整异常消息 |
| `created_at` | 任务登记时间；文件删除成功后删除任务，失败保留并在 5 分钟后重试 |

### 支付 `payments`
| 字段 | 含义 |
|---|---|
| `product` | TRIP_PRO：单段旅行升级；LIFETIME：终身 Pro |
| `amount` / `currency` | 最小货币单位（分）/ CNY |
| `provider` / `provider_payment_id` | 支付渠道与渠道侧单号（唯一，用于 Webhook 幂等） |
| `order_user_id` / `order_trip_id` | 创建订单时的归属快照；删除账号或旅行后保留财务关联编号，不用于授予权限 |
| `checkout_key` / `checkout_url` | 待付款账号唯一键 / 原付款页；订单结束后释放唯一键 |
| `payment_intent_id` / `charge_id` | Stripe 付款及扣款关联，用于核实渠道结果 |
| `refunded_amount` / `dispute_id` / `dispute_status` | 累计退款金额（分）及渠道争议状态 |
| `last_synced_at` / `last_checked_at` | 最近成功同步 / 最近查询尝试，失败退避不会伪装成功同步 |
| `payment_events` | 已处理渠道事件 ID、订单与类型；同事务写入，避免并发重复处理 |
| `users.lifetime_pro_grant` / `trips.pro_grant` | 非付款赠送权益；退款重算时保留 |

### 其他
| 表 | 要点 |
|---|---|
| `refresh_tokens` | 一行是一次签发；`session_id` 把同一设备的多次轮换串成一个会话；`user_agent` 用于显示设备 |
| `memberships` | 账号会员；`expires_at` 为空 = 永久；`payment_id` 关联开通它的支付 |
| `user_music` | `original_filename` 只用于展示，存储路径是随机的 `storage_key` |
| `email_verifications` | 验证码只存 `code_hash`（HMAC-SHA256），令牌只存 `token_hash`（SHA-256）；IP 只存哈希 |
| `video_music` | 曲目的完整授权记录（许可证、署名、是否可商用 / 改编、核验时间、文件哈希）；`object_key` 原曲、`preview_key` 45 秒试听 |
| `destinations` | 创建旅行时的目的地搜索数据；`official_city_code` 有值表示该城市有官方探索内容 |
| `official_routes.place_ids` | 逗号分隔的地点 id，顺序就是游览顺序 |
