# 枚举与常量定义

**一个值只在一处定义。** 本表列出每个值的定义位置；改值时改定义处，再同步本表。后端常量通过 `GET /api/v1/plans/trip-pro`、`GET /api/v1/user/music` 等接口下发给前端，前端不另写数值。
（代码路径省略前缀 `backend/api/src/main/java/com/tabitrace/`。）

## 1. 状态与类型

数据库都是 `VARCHAR`，没有 ENUM / CHECK。状态转换见 [状态与生命周期](../02_business/04_状态与生命周期设计.md)。

| 字段 | 取值 | 定义 / 校验位置 |
|---|---|---|
| `users.status` | ACTIVE、DELETION_PENDING | `UserService.STATUS_DELETION_PENDING`、`AuthService` |
| `trips.plan_type` | FREE、PRO | `TripService`、`PaymentService` |
| `trips.status` | PLANNING、ONGOING、COMPLETED、ARCHIVED | `TripService`、`CheckinService` |
| `trips.visibility` | PRIVATE、UNLISTED | `TripService`、`ShareService` |
| `places.source_type` | OFFICIAL、CUSTOM | `PlaceService`、`OfficialCityService` |
| `itinerary_items.status` | PLANNED、DONE、CANCELLED | `ItineraryService.normalizeStatus` |
| `checkins.checkin_type` | MANUAL | `CheckinService` |
| `achievements.type` | GLOBAL、CITY | V2 |
| `achievements.condition_type` | CHECKIN_COUNT、PHOTO_COUNT、AREA_COUNT、TRIP_COMPLETED、OFFICIAL_CHECKIN_COUNT、TOKYO_TRADITION、TOKYO_NIGHT | V2、`AchievementService` |
| `share_links.status` | ACTIVE、REVOKED | `ShareLinkMapper` |
| `payments.product` | TRIP_PRO、LIFETIME | `PaymentService.PRODUCT_*` |
| `payments.status` | PENDING、PAID、FAILED、EXPIRED、PARTIALLY_REFUNDED、REFUNDED、DISPUTED | `PaymentTransactions` |
| `memberships.source` / `status` | LIFETIME、SUBSCRIPTION、GRANT / ACTIVE、CANCELLED、REVOKED（读取时另算出 EXPIRED） | V15、`MembershipService` |
| `user_music.status` | UPLOADING、PROCESSING、READY、FAILED、DELETED | `UserMusicService` |
| `video_projects.status` | DRAFT、QUEUED、PROCESSING、COMPLETED、FAILED | `VideoService`、Worker `VideoJobPoller` |
| `video_projects.render_stage` | PREPARING …（渲染阶段）、UPLOADING | Worker |
| `video_projects.renderer` | FFMPEG、MOCK | Worker、`VideoMockRenderer` |
| `video_projects.music_source` | SYSTEM、USER、NONE | `VideoService` |
| `video_projects.aspect_ratio` | 9:16、4:5、16:9 | `VideoService.SUPPORTED_RATIOS` |
| `video_projects.quality` | 720p、1080p | `VideoService` |
| `video_templates.code` | JOURNAL（旅行日记，FREE）、MINIMAL（极简杂志，PRO）、CITY（城市节奏，PRO） | V3 |
| `video_music.status` | REVIEW_REQUIRED、APPROVED | V10 |
| `video_music.category` | WARM、CITY_NIGHT、MORNING、LOFI、CINEMATIC | V14 |
| `email_verifications.purpose` | REGISTER、RESET_PASSWORD、CHANGE_EMAIL（未启用） | `VerificationPurpose`、`EmailVerificationService.ENABLED` |
| `email_verifications.send_status` | PENDING、SENT、FAILED、THROTTLED | `EmailVerificationMapper` |
| `official_cities.status` | DRAFT（默认）、ACTIVE | V1、`OfficialCityMapper` |
| `users.distance_unit` | KM、MI | `UserService.DISTANCE_UNITS` |
| `users.locale` | zh-CN、ja-JP、en-US | `UserService.LOCALES` |

## 2. 套餐与权益数值

| 常量 | 值 | 定义位置 |
|---|---|---|
| FREE 同时保留的未归档 FREE 旅行数 | 1 | `TripService.FREE_ACTIVE_TRIP_LIMIT` |
| FREE 每段旅行打卡数 | 10 | `CheckinService.FREE_CHECKIN_LIMIT` |
| FREE 每段旅行照片数 | 10 | `PhotoService.FREE_PHOTO_LIMIT` |
| Trip Pro 价格 | 400 分（¥4，CNY） | `PaymentService.TRIP_PRO_AMOUNT` / `TRIP_PRO_CURRENCY` |
| 终身 Pro 价格 | 100000 分（¥1000） | `PaymentService.LIFETIME_AMOUNT` |
| 支付本地最低金额阈值（默认） | 400 分；Stripe 实际限制以商户结算币种为准 | `PaymentService.DEFAULT_STRIPE_MIN_AMOUNT`（可用 `app.payments.stripe.min-amount` 覆盖） |
| 视频照片数 FREE / PRO | 10 / 30 | `VideoService.FREE_MAX_PHOTOS / PRO_MAX_PHOTOS` |
| 视频时长 FREE / PRO | 15、30 / 15、30、60 秒 | `VideoService.FREE_DURATIONS / DURATIONS` |
| 视频清晰度 FREE / PRO | 720p / 1080p | `VideoService.FREE_QUALITY / PRO_QUALITY` |
| 每个用户同时生成的视频数 | 2 | `VideoService.MAX_ACTIVE_RENDERS_PER_USER` |
| 分享图规格 FREE / PRO | STANDARD、海报宽 1080、1 倍、九宫格单张 720、水印 / HD、1440、2 倍、1080、无水印 | `PlanService.SHARE_FREE / SHARE_PRO` |

## 3. 文件与上传

| 常量 | 值 | 定义位置 |
|---|---|---|
| 照片原图上限 | 20MB | `PhotoService.PHOTO_MAX_BYTES`（前端 `PHOTO_MAX_BYTES` 必须一致） |
| 缩略图 / 中图上限 | 1MB / 5MB | `PhotoService.THUMB_MAX_BYTES / MEDIUM_MAX_BYTES` |
| 照片类型 | JPG、PNG、WebP、GIF、HEIC | `PhotoService` |
| 头像上限 / 类型 | 5MB / JPG、PNG、WebP | `UserService.AVATAR_MAX_BYTES / AVATAR_TYPES`（前端 `AVATAR_MAX_BYTES` 一致） |
| 我的音乐：单个 / 首数 / 总量 / 时长 | 30MB / 20 首 / 500MB / 3 秒～30 分钟 | `app.user-music.*`（application.yml，可用环境变量覆盖） |
| 我的音乐格式 | MP3、M4A、WAV | `UserMusicService.EXTENSIONS / MIME_TYPES` |
| 预签名上传有效期 | 15 分钟 | `LocalStorageService.UPLOAD_TTL_SECONDS` 等 |

## 4. 账号与安全

| 常量 | 值 | 定义位置 |
|---|---|---|
| 访问令牌 / refresh token 有效期 | 15 分钟 / 30 天 | `app.jwt.*` |
| refresh Cookie | `tt_refresh`、HttpOnly、SameSite=Strict、path `/api/v1`、生产 Secure | `app.auth.refresh-cookie.*` |
| 密码长度 | 8～100 | `AuthDtos` |
| 昵称 / 简介长度 | 30 / 120 | `UserService.NICKNAME_MAX / BIO_MAX` |
| 分享链接默认有效期选项 | 0（长期）、7、30 天 | `UserService.SHARE_EXPIRY_DAYS` |
| 验证码有效期 / 最多错误次数 / 重发间隔 | 600 秒 / 5 次 / 60 秒 | `app.email-verification.*` |
| 验证码频率 | 同邮箱每小时 5 次、同 IP 每小时 20 次 | 同上 |
| 邮箱验证令牌有效期 | 1800 秒 | 同上 |
| 登录失败限流 | 15 分钟内同邮箱 8 次、同 IP 40 次 | `app.login-throttle.*` |
| 注销冷静期 | 7 天 | `AccountDeletionService.COOLING_OFF_DAYS` |
| 已过期 / 撤销会话保留 | 7 天后清理 | `SessionCleanupService.KEEP_DAYS` |
