## 业务边界与保护

- 邀请用于引导现有公开注册，撤销邀请不封禁邮箱的公开注册。不会代建账号、代设密码或绕过邮箱验证码。邮件失败返回真实错误并回滚本次邀请记录；同一待处理邮箱唯一，重发至少间隔一分钟。
- 账号删除沿用现有 7 天冷静期及到期文件清理流程。唯一管理员不能删除，管理员删除可作用于停用普通用户，撤销时保留其停用状态。财务审计数据继续按既有规则保留。
- 旅程 / 媒体永久删除有确认输入，后台根据数据库推导归属，不接受浏览器自报 ownerId。删除复用原有存储和视频清理逻辑；失败按原规则回滚或进入持久化重试，不伪报文件已经全部清理。
- 默认权限只影响之后注册的账号，注册事务锁定默认设置，与管理员保存确定先后顺序。原有 20 次 / 6000 秒 / 同时 3 个视频任务的成本配置仍独立生效；本页只读展示，不动态改写环境变量。
- 所有新增读取与写入均受服务端 ADMIN 角色和账号状态保护。管理写入与留言回复共用管理员行锁、每分钟 60 次限制；资料变更使用原样微秒版本，账号 / 旅程更新时间单调递增。审计不记录密码、邀请邮件正文或存储密钥。
- 维护任务面向当前单 API 实例，最多一个排队 / 执行任务，完成结果保存失败会重试；重启将中断的执行任务标记失败、保留排队任务。未来多 API 实例须增加分布式租约。维护只清理原规则已经到期 / 可清理的资源，不绕过冷静期；视频输出仍由 Worker 重试清理。
