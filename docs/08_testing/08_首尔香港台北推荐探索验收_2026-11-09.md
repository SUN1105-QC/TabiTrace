# 首尔、香港、台北推荐探索验收（2026-11-09）

## 内容与图片流程（可复用）

1. 内容源：`frontend/assets-src/places/EXPANSION_CITIES.json`（地点、区域、分类、标签、简介、停留时长、路线），个别换图/坐标写在 `EXPANSION_OVERRIDES.json`。参考来源为各城市官方旅游网站。
2. `node frontend/scripts/prepare-expanded-explore.mjs metadata`：从 Wikipedia / Wikidata 取坐标和代表图；`preflight`：核对 Commons 授权与尺寸；`images`：下载 **Commons 原图**、校验坐标在城市范围内、生成四档 WebP、写授权记录。
3. `node frontend/scripts/generate-expanded-explore-sql.mjs`：生成 V24 迁移。不手写 SQL。

授权分布（90 张）：CC BY-SA 4.0 37、CC BY 2.0 9、CC BY-SA 3.0 9、KOGL Type 1 8、CC BY 4.0 7、CC BY 3.0 6、CC0 4、公有领域 3、CC BY-SA 2.0 3、Attribution（GWOIA）2、CC BY 2.0 kr 1、CC BY-SA 2.5 1。全部有作者署名，授权链接均为 https。

## 本轮接续修正

上一轮已完成内容、图片、迁移、城市页与大部分测试；本轮接手后发现并修正：

| 问题 | 处理 |
|---|---|
| 新城市图片下载的是 Commons 1920px 缩略图，「2560 档」实际只有 1920（部分 1280），与东京用原图生成不一致 | 脚本改为下载原图并按字节数识别旧缓存，重新生成 90 张。现在 63 张有真正的 2560 档；其余原图本身不足 2560，按规则不放大 |
| 9 条授权链接为 `http://creativecommons.org`，单测失败 | 改为 https，脚本同步规范化 |
| 士林夜市缺作者 | 按 Commons 页面补为上传者 Changlc（PD-self，2004-12-29 拍摄）；脚本重跑时保留已核对的署名 |
| 中国主题内台北排在香港前（V23 的台北排序未被 V24 覆盖） | 生成器的 upsert 同步 `sort_order`，重新生成 V24，迁移测试加断言 |
| `check-expanded-cities.mjs` 注入脚本中的正则在模板字符串里丢了反斜杠，写操作模拟失效；目的地搜索被当作公开接口 | 正则改为不含反斜杠的写法；目的地搜索改为断言「仍需登录」，关联关系由迁移测试在数据库层断言 |
| `check-explore-directory.mjs` 写死「只有东京开放」 | 预期值改为从公开目录接口推导；「仅看开放 → 空结果恢复」改用日本 + 京都 |
| `public-smoke` 只覆盖东京城市页 | 加入三座新城市页 |
