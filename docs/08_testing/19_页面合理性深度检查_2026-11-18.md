# 页面合理性深度检查 · 2026-11-18

本轮状态：本地完成，未提交、未发布。保留 11-17 未发布的移动首页与电脑旅行菜单改版。正式站仍为通知面板发布版本。

## 检查范围与方法

- 首轮 30 个页面状态 × 4 种尺寸，共 120 个页面视图；扩展后复查 38 个状态 × 4 种尺寸，共 152 个视图，另对末轮微调的 6 类页面复查 24 个视图。
- 尺寸为 375×812、768×1024、1024×768、1440×900。首页 / 地图 / 相册 / 分享另有 320、390、1920px 回归。浏览器使用 Chromium，窄屏及平板开启触屏模拟。
- 包含访客首页、登录、注册、密码找回、探索目录和四座城市、定价、图片署名、公开分享；登录后首页、旅行列表 / 创建、地图、相册及高级筛选、分享六种状态、视频、回忆、设置六个标签页、活动列表、联系管理员和 404。
- 后台单独覆盖用户与权限、邀请、留言、旅程、媒体、全局设置、审计、维护及手机抽屉。
- 数据与业务写入由浏览器夹具隔离。只读的公开目录 / 方案可使用现有本地 API；没有发真实邮件、创建账号、付款、上传照片或改动生产库。

## 已修复的问题

| 区域 | 原问题 | 修正行为 |
|---|---|---|
| 当前旅行 | 打开旅行列表会重新选择首条未归档旅行，覆盖用户已选项 | 仅在当前账号的返回列表中解析记忆值，保留主动选择的归档旅行；失效 ID 安全回退 |
| 旅行列表 | 网络失败只提供去登录入口；统计失败显示 0；建议区为不可点击的展示行 | 增加原地重试，缺失统计用 `—` 并提示，建议区成为携带当前旅行 ID 的真实链接；归档使用回看文案 |
| 全局搜索 | 任意关键词都混入照片；缩短关键词后加载状态可能残留；部分读取失败被隐藏 | 按照片标记、时间和关联打卡信息匹配；清除过期官方结果和加载状态；读取失败可重试，已有结果及功能入口继续可用 |
| 搜索交互 | 可通过 Tab 跳到遮罩后方；关闭后焦点丢失；输入法确认可能触发跳转 | 锁定背景滚动、约束键盘焦点、恢复入口焦点，组合输入期间不执行跳转；增加活动 / 联系管理员 / 设置入口 |
| 通知 | 桌面和手机各有一份已读状态；多个账号共用时间戳 | 按账号保存已读时间，并同步同页两套顶栏及其他标签页；常驻账号规则仍不计入未读数量 |
| 地图 / 分享 / 视频 / 顶栏 | 切换旅行时旧请求可能晚到并覆盖新内容 | 使用读取序号或取消标记隔离旧概览、地图、分享、视频分镜及视频轮询响应；切换时重置旅行相关临时编辑状态 |
| 分享读取与预览 | 初次失败缺少重试，旧错误不清理；很高的成品预览仍吸顶 | 增加初次读取重试；成功后清除错误；超过视口可用高度的预览随页面自然滚动，短预览保留原吸顶行为 |
| 相册 / 上传 / 大图 | 键盘焦点可落到背景，Select 聚焦时 Escape 无法关闭详情；坏图仍显示破损图片 | 共用模态焦点边界和背景滚动锁定；Escape 与 Select 分开处理，关闭恢复焦点；卡片 / 大图补可理解的错误占位 |
| 头像 | 桌面页头与设置头像加载失败时显示破图 | 回退昵称首字，换新头像地址后可重新加载 |
| 触屏 | 景点名称、视频素材排序 / 封面 / 删除、模板圆点、比例按钮、设置开关和下载链接偏小 | 针对性扩展可点击区域或实际占位；视频素材用 44px 按钮并相应扩宽卡片；地图缩放、回忆作品链接同步调整 |
