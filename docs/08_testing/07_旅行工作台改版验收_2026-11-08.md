# 旅行工作台改版验收（2026-11-08）

已部署到 https://tabi.sunows.com ，Web版本 `usability-20261108-v3`。本轮落实导航、首页、手机地图、照片整理、创建表单与导出流程；交互预览使用的演示数据没有进入产品。

## 上线范围

- 全局导航收拢为首页、我的旅行、推荐探索、旅行回忆；旅行内显示当前旅行、日期、状态和切换入口。
- 首页突出当前旅行、记录这一刻、下一站、最近活动与照片。地图、照片、导出、视频及页头、手机打卡入口同步当前旅行。归档入口明确说明只读，不会悄悄切换到其他旅行。
- 手机地图分为行程、地图、记录，取消第二层固定操作栏；添加地点放入行程面板。移除行程和撤销打卡先说明影响并确认。
- 照片页保留全部/精选，其余条件和排序收纳，添加照片放在标题附近，扩大常用卡片按钮点击区域。
- 创建页目的地前移，预览和自动准备说明折叠，取消手机额外固定的创建按钮；修复320px目的地输入的轻微溢出。
- 导出分享按旅行记录、图片作品、访问链接组织。手机图片素材先于预览，提供选材/预览/导出定位入口。九宫格显示实际已填、自动、手动及空位数量，不足九张继续留空。记录继续支持PDF、PNG、JPG、CSV和地图联合导出；创建链接前展示当前有效期与位置精度规则。
- 操作主色采用 `#B54C1E`，保留暖色旅行风格及作品画布自身配色。
