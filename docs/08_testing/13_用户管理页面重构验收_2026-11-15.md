## 实施前审计与适配边界

技术栈沿用 Next.js 16 / React 19 / TypeScript、既有 API client、CSS Modules、Lucide 图标；后端沿用 Spring Security / MyBatis / MySQL。不添加 UI 库或新的角色体系。原后台源码快照保存在本机忽略目录 `backend/.tabitrace/admin-users-redesign/before/`；本次不发布生产、不执行数据库初始化。

| 页面需求 | 现有能力 | 本次接入范围 |
|---|---|---|
| 管理员认证 | `/users/me`、JWT / HttpOnly refresh Cookie；`/admin/**` 服务端 ADMIN 授权 | 复用，非管理员不读取后台数据 |
| 七项统计 | `/admin/overview` 的 users / trips / photos / openMessages / videos / activeRenders / pendingDeletionTrips 等字段 | 真实聚合、独立加载与失败反馈，不写死截图人数 |
| 用户列表 | `/admin/users?q=&page=`，每页 25，ID 降序 | 补状态筛选与 10 / 25 / 50 分页，条件写入 URL |
| 用户详情 | 尚无独立详情接口 | 补只读详情，按 ID 读取最新值与真实头像 |
| 权限保存 | `PUT /admin/users/{id}`，事务锁账号并记录审计 | 保留路径和完整更新语义；以现有 updated_at 做冲突检查，不加数据库列 |

## 已实现的页面与交互

- 深绿侧栏与山形品牌、可折叠桌面导航和窄屏模态导航；只展示已有概览、用户与留言入口。
- 七张实时统计卡片采用桌面 4+3 / 平板双列 / 手机单列布局。统计和当前列表独立加载、失败和重试；同步状态来自最近的真实请求结果。
- 用户列表使用后端搜索、状态筛选、10 / 25 / 50 条分页与稳定 ID 排序。300ms 防抖、Enter 立即搜索、空状态重置、页码越界纠正、URL 持久化与过期请求取消。
- 用户头像只用已有头像 URL，否则姓名首字；没有随机照片。桌面表格、手机用户卡片均可编辑；注销冷静期账号只读。
- 桌面下方权限面板，手机全屏编辑抽屉；草稿与服务器详情分离。切换用户、栏目、返回、退出及页面关闭保护未保存内容。
- 数字范围前后端校验；缩短月份和停用账号必须确认。409 冲突保留草稿并提供重载；403 / 422 / 500 / 离线不提示假成功。
- 保存后使用权威响应更新详情，并刷新列表和概览；不因降低配额删除已有旅程。留言回复和待处理数量同步更新，正文以安全文本显示。
- 使用原生 dialog 管理焦点、Esc、背景隔离与关闭后焦点恢复；手机保存栏固定在可触达区域，尊重减少动画偏好。

## API 适配与并发

路径统一保留 `/api/v1` 前缀。七项统计直接使用原 `/admin/overview` 字段，排队 / 渲染使用现有合计 `activeRenders`，不虚构单独计数。有效旅程与 7 天到期统计按服务端 UTC 计算；保留月份从创建时间起算。

`GET /admin/users` 增加 status / pageSize，返回原有分页结构。新增 `GET /admin/users/{id}`，返回 avatarUrl / updatedAt。`PUT /admin/users/{id}` 继续完整更新允许字段，增加必填 `expectedUpdatedAt`，返回最新用户。管理功能当前未发布，前后端需一同更新，旧开发页面须刷新后读取并回传令牌；时间戳不转换为 JS Date，保留微秒精度。

比较与更新在账号行锁内执行；updated_at 单调递增，过期版本返回 409。权限写入同时锁住唯一管理员，并以 READ COMMITTED 读取最近一分钟的成功审计，避免等待锁后仍读旧快照绕过 60 次限额。普通用户 / 注销中账号 / 管理员保护沿用原规则。成功写入记录操作人、目标、前后值、UTC 时间、操作标识及结果；不记录密码、Token 或密钥。

原 `GET /admin/messages` 数组接口保留；新增 `/admin/messages/page` 返回总数分页。原回复接口与用户侧 `/support/messages` 不变。所有后台接口继续由 Spring Security 和 service 双重校验 ADMIN 角色；页面不会在鉴权前请求后台资料。

cd frontend

cd ..
node e2e/tools/check-admin-users.mjs

mvn -o -B -ntp -pl api '-Dtest=*Test,!MySql*' test
