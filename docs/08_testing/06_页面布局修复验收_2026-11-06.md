# 页面布局修复验收（2026-11-06）

本次处理 [11 月 5 日布局审查](05_页面布局与样式审查_2026-11-05.md) 的 L01–L05。产品改动集中在全局样式、搜索结果标记和旅行列表容器，保持原有页面结构与业务流程。

## 修复内容

| 问题 | 实现 |
|---|---|
| L01 平板侧栏点击被遮罩拦截 | 打开状态的侧栏层级提升到 76，高于遮罩的 75。保留菜单、关闭按钮和遮罩外部点击各自的行为。 |
| L02 搜索结果挤在同一行 | 结果按钮采用专用 `.command-result` class，恢复整行宽度、留白、左右对齐和悬停/焦点背景；文字容器允许长词折行，箭头不被压缩。 |
| L03 横屏搜索底部被裁切 | 遮罩按 `100dvh` 布局；弹窗使用纵向 flex、可收缩高度，输入区固定，结果区内部滚动，保留桌面最大高度。 |
| L04 长标题撑宽多个页面 | 分享标题折行；首页最近活动、旅行列表和回忆卡片标题最多显示两行，价格状态卡标题最多三行，并保留完整文字及标题提示；旅行列表使用可收缩的 grid 列和卡片子项；回忆页年月时间轴限制列宽；价格页约束旅行选择器、升级/成功提示、功能对比文案及底部购买条标题。 |
| L05 时间轴多张照片撑宽窄屏 | 照片列自动换行，每个缩略图和计数块固定 72×72px，不再不均匀压缩。 |

L04 的价格页在首轮回归中仍有功能对比文案溢出；定位到 `.pr-compare-hint` 后一并修正，最终验收以修正后的生产构建为准。

- `npm run typecheck`：通过。
- `npm run lint`：0 个错误，104 条既有警告。

## 重跑

启动测试前端，确保公开方案与目录 GET 接口可用，然后在仓库根目录运行：

```powershell
$env:LAYOUT_TEST_WEB = 'http://127.0.0.1:3015'
node e2e/tools/check-layout-regressions.mjs
```

默认结果保存到 `backend/.tabitrace/layout-regression/`，可用 `LAYOUT_TEST_OUTPUT` 修改路径。复现数据位于 [layout-ui.mjs](../../e2e/fixtures/layout-ui.mjs)，执行工具位于 [check-layout-regressions.mjs](../../e2e/tools/check-layout-regressions.mjs)。
