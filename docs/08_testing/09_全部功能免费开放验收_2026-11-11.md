# 全部功能免费开放验收（2026-11-11）

按用户要求开放全部付费功能，并在当天发布上线：版本 `open-access-20261111-c32b709b`，由提交 `c32b709` 构建，CI 第 12 次运行通过。设计见 [ADR-026](../99_management/04_设计决策记录.md)。

## 做了什么

| 层 | 开关打开时 |
|---|---|
| 开关 | `app.plans.open-access`（环境变量 `PLANS_OPEN_ACCESS`，`common.PlanAccess`）。代码默认关闭，生产 Compose 默认开启 |
| 旅行 | 新建旅行直接是 PRO，不再限制 FREE 旅行数量。API 启动时把已有 FREE 旅行升级为 PRO（`OpenAccessTripUpgrade`）。升级只单向进行，关闭开关后这些旅行仍保留 PRO。打卡、照片、视频（1080p、60 秒、全部模板、30 张照片）和分享图（高清、无水印）都沿用原有的「按 `plan_type` 判断」，Worker 不需要改 |
| 会员 | 没有有效会员记录的账号也按有效会员处理，来源为 `OPEN_ACCESS`，只在读取时算出、不写库。「我的音乐」可以直接上传和使用 |
| 付款 | 新付款和继续未完成的订单都返回 `PLANS_OPEN_ACCESS`（409），不写订单 |
| 接口 | `GET /plans/trip-pro` 和 `GET /users/me/overview` 增加 `openAccess` |
| 前端 | 升级页只保留权益说明和成果展示，不显示价格、对比、购买 FAQ 和购买条；侧栏入口改为「全部功能已免费开放」（中英日三语）；设置页显示「所有旅行都是 Trip Pro」；首页方案区与结尾文案改为免费开放 |
| 不变 | 视频成本限额：账号每日 20 次 / 6000 秒，每账号同时 2 个、全站同时 3 个任务 |

恢复收费：在服务器 `shared/.env` 设 `PLANS_OPEN_ACCESS=false`，然后重启 API 和 Web。不需要迁移。
