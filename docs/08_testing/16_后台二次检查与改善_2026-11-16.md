# 后台二次检查与改善 · 2026-11-16

本轮按用户“再次检查后台管理系统页面，进行问题修改和改善”的要求复查。改动集中于后台前端，不修改后端接口、业务数据库或账号权限规则。

## 发现与修复

| 问题 | 修改后的行为 |
|---|---|
| 桌面侧栏收起后，分组按钮被隐藏，日志等栏目无法进入 | 收起时保留分组图标、标题和展开行为，所有栏目仍可访问 |
| 矮屏侧栏末项可能被固定页脚覆盖 | 导航独立滚动，品牌与页脚不参与滚动；420px 高度可到达运行维护 |
| “首页概览”和面包屑首页只滚动当前页面 | 接入独立 `?tab=overview`，展示真实七项概览与六个功能入口；导航仍经过草稿 / 保存保护 |
| 通过快捷入口或返回切换栏目后，当前项可能藏在关闭分组里 | 切换到用户 / 日志栏目时展开对应分组，保留当前项高亮 |
| 更换查询后仍短暂暴露上次结果，旧总数可能把新查询页码改回第一页 | 读取状态与 loader / 启用状态关联，第一帧就隐藏旧结果，等待当前查询返回后才修正真正越界的页码 |
| 手动接受保存后的详情仍可能残留读取错误或被旧读取覆盖 | 写入返回的权威资料取消旧详情请求，并清空旧错误与读取状态 |
| 默认权限已保存，但重读失败后被误判为未保存 | 保存成功即更新编辑基线；重读错误单独显示，离开不再误报有草稿，重置使用最后成功保存的值 |
| 自动轮询每 5 秒取消较慢的读取，维护结果可能一直读不到 | 读取期间暂停轮询，完成或失败后再安排下一轮；页面重新可见时补读。并行读取有一个失败时取消其余悬挂请求 |
| 内容 / 媒体筛选为空后缺少一键恢复入口 | 显示当前筛选与“清除筛选”，同时恢复第一页；审计操作增加中文名称和原操作代码 |
| 手机设置、媒体等栏目需先经过七张重复全局指标卡 | 大块全局指标保留在概览、用户和留言页；其余栏目直接呈现业务内容。设置表单首个输入在手机首屏可见 |
| 顶栏同步时间一直取全局概览时间 | 改为当前栏目 / 列表实际完成读取的时间；独立栏目不受隐藏的概览请求错误影响 |
