# 全页面审查与修复（2026-11-13）

用户要求对全部页面做一次深度检查，覆盖电脑、手机、Pad 三端，发现问题就修正和完善。本次只改前端，API、Worker、数据库都不变。

## 1. 方法

新增 `e2e/tools/audit-all-pages.mjs`，以后可以直接复跑：

```bash
AUDIT_WEB=http://localhost:3000 node e2e/tools/audit-all-pages.mjs
```

- **测试数据**：只在浏览器里注入（`e2e/fixtures/layout-ui.mjs`），不写入真实业务数据。脚本另外补了三类模拟接口：公开分享页、视频模板、「我的音乐」库。
  - 原来的测试数据没有这三类接口，视频页在测试环境里会显示「加载失败」，电脑宽度下会直接崩溃。这只是测试数据缺失，不是线上问题。
- **页面**：共 30 个页面状态。
  - 访客：首页、登录、注册、找回密码、推荐探索、四座城市、定价、署名页、公开分享页。
  - 登录后：首页、我的旅程、新建旅行、地图、相册（另含筛选展开状态）、分享（九宫格、手帐、长图、海报、旅行记录、访问链接）、视频、回忆、设置、定价、探索。
- **尺寸**：手机 375×812、Pad 竖屏 768×1024、Pad 横屏 1024×768、电脑 1440×900。宽度小于 1100 时按触屏模拟。
- **截图**：每页按真实视口逐屏截图，最多 6 屏。整页截图会临时放大视口，让 vh 和缩放框失真，所以不用。截图逐页人工查看。
- **自动指标**：
  - 横向溢出
  - 文字被截断
  - 触屏点击区域小于 32px（伪元素扩大的区域也算进去）
  - 手机上小于 11px 的字
  - 加载失败的图片
  - 脚本报错
  - 未拦截的接口请求
- **访客对照**：用全新、未登录的浏览器只读打开正式站，确认问题在线上真实存在。

## 2. 发现与修复

| # | 问题 | 范围 | 修复 |
|---|---|---|---|
| 1 | 未登录访客打开推荐探索、城市页、定价页，看到的是登录后的工作区外壳：通知铃、占位头像、「搜索自己旅程」的搜索框、底部的打卡 / 我的导航，头部却没有「登录」。正式站已确认存在 | 三端 | `SiteHeader`：`/explore`、`/pricing` 只在已登录时用工作区外壳，访客改用公开导航。服务端渲染和挂载之前仍按工作区渲染，避免已登录用户看到闪烁 |
| 2 | 改成公开导航后，手机和 Pad 上推荐探索目录页的内容贴着屏幕边缘（原来靠工作区外壳统一加边距） | 手机、Pad | 只在访客、≤1023px 时补 16 / 32px 左右边距（`.xp-directory-page`）；登录后的排版不变 |
| 3 | 视频、旅行回忆、推荐探索、行程详情（手机）、落地页的主按钮仍是浅橙（`#F2762E` / `#E97A33`），白字对比度不足 3:1，和其他页面的操作主色也不一致 | 三端 | 这些页面的颜色变量、探索目录的 `--accent`、Tailwind 的 `warm` 统一为 `#B54C1E`（白字对比度约 5.9:1） |
| 4 | 触屏上一批文字链接和小控件只有 16～31px 高：地图的「导航 / 查看记录」、时间轴地点名、删除图标；回忆页「打开 / 管理」和跳转标签；探索页面包屑、「查看全部 / 更换」、视图切换；分享页的日期标签；视频模板切换点、步骤条、素材筛选、播放键；相册视图切换；我的旅程「新旅行」；公开导航链接。原有的放大规则只在 ≤767px 生效，iPad 上没有 | 手机、Pad | `@media (pointer:coarse)` 下用透明伪元素把点击区域扩大到约 36～44px，外观和排版不变；首页旅行切换框最小高度 44px |
| 5 | 界面里有 8～9.5px 的字：推荐探索目录的小标题、国家英文名、标签、说明；视频模板英文名和 FREE / PRO 标记；城市页「x 个地点」 | 三端 | 调到 10～11px（导出成品里的设计排版不动） |
| 6 | 手机和平板上，城市海报的素材面板里还有一个「导出 PNG」，排在预览之前，和预览下方的导出区重复 | 手机、Pad | ≤1279px 时隐藏面板内的按钮，电脑端保留 |

## 3. 排查后不算问题

| 现象 | 结论 |
|---|---|
| Pad 横屏相册的筛选框「超出屏幕」 | 收起状态的 `<details>` 内容仍有布局盒子，是误报；展开后没有溢出。审查脚本已排除收起的内容 |
| 视频页「加载失败 / 请先登录」、电脑宽度下整页崩溃 | 测试数据缺视频模板和音乐库的模拟接口；补上后四种尺寸都正常 |
| 电脑端分享页的预览区是很高的 sticky 元素 | 预览就是该栏最高的内容，没有可吸附的空间，表现为正常滚动 |
| 城市页地图上的地点标签只有 21～28px | 属于地图标注，用户可以缩放地图，不改 |
| 分享页素材复选框 13px、探索页复选框 16px | 外层有标签，整行都可以点击 |
| 回忆页「去年的秋天，你在京都」配四月的旅行 | 测试数据人为把四月的旅行标成「同季节」；真实数据由后端按季节筛选 |
