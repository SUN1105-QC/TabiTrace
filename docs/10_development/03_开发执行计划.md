## 3. 下一阶段：M3 · 测试环境可用

**目标**：在 Railway 测试环境用真实外部服务跑通核心链路，补齐上线前必需的合规页面和自动化检查。

**任务**
1. 隐私政策 / 服务条款（含退款说明）页面，配置 `LEGAL_LINKS`，注册页显示同意项，页脚不再「即将发布」（内容需要用户提供或确认）。
2. CI 移到仓库根目录 `.github/workflows/`：后端测试 + 前端 typecheck / lint / test / build。
3. 部署 web / api / worker / MySQL 8.4，接入真实 R2（照片与音乐分桶）、邮件服务商、地图底图服务商。
4. 删除视频 / 旅行时同时删除成片文件（P1）。
5. 在测试环境执行空库迁移验证和 E2E（critical-path、storage、email）。

**验收标准**
- 测试环境 `/health` 返回 `{"status":"ok"}`，api 健康检查通过。
- 真实邮箱收到验证码并完成注册；照片上传到 R2 并正常显示；Worker 生成带音乐的视频并能播放。
- 推送后 CI 自动运行且全绿。
- `/privacy`、`/terms` 可访问，注册页能链接过去。
- 删除视频后成片地址不可访问。
- 相关 P1 关闭或有明确结论。
