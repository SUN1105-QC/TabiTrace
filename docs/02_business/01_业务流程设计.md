# 业务流程设计

只描述流程和关键分支；每一步的限制条件见 [用例与业务规则](03_用例与业务规则.md)，状态变化见 [状态与生命周期](04_状态与生命周期设计.md)。

## 1. 主旅程

```
访问首页（未登录看产品介绍 Landing）
↓
注册：填邮箱 → 收 6 位验证码 → 验证得到一次性令牌 → 设置昵称和密码 → 自动登录
↓
创建旅行：标题、目的地（搜索）、起止日期、人数
  ├─ 目的地有官方内容（东京）且勾选「加入官方探索」→ 30 个官方地点自动加入旅行
  └─ 其他目的地 → 自由旅行模式
↓
行前：推荐探索里收藏 / 加入地点；地图页安排行程（日期、时间、备注）
↓
旅途中：快速打卡 / 手动打卡 / 行程一键打卡；上传照片、标记精选
  （第一次打卡时旅行从 PLANNING 变为 ONGOING；成就随打卡和照片自动计算）
↓
旅行后：看总结 → 标记完成（COMPLETED）
↓
成果：海报 / 九宫格 / 长图（浏览器导出 PNG）；分享链接；Travel Story 视频
↓
需要更多额度或高清无水印 → Trip Pro（单段旅行）或终身 Pro（账号）
↓
回看：旅行回忆
```

## 2. 注册与登录

```
发送验证码（purpose=register）
  ├─ 冷却 60 秒内 / 同邮箱每小时 5 次 / 同 IP 每小时 20 次 → 429 + retryAfter
  ├─ 邮箱已注册 → 响应与正常发送相同，但邮件内容是「请直接登录」，不含验证码（防探测）
  └─ 正常 → 邮件里 6 位验证码（10 分钟有效，最多错 5 次）
↓
校验验证码 → 一次性 emailVerificationToken（30 分钟有效）
↓
注册（邮箱、密码 8~100 位、昵称、令牌、界面语言与时区）→ 返回访问令牌，refresh token 写入 HttpOnly Cookie
```

登录：邮箱或密码错误统一返回 `INVALID_CREDENTIALS`；15 分钟内同邮箱失败 8 次或同 IP 失败 40 次 → 429。账号处于注销冷静期时返回 `ACCOUNT_DELETION_PENDING`，用户确认后带 `cancelDeletion=true` 再登录即撤销注销。

忘记密码：验证码（purpose=reset_password）→ 令牌 → 设置新密码 → 撤销该账号所有会话，当前设备直接登录。

## 3. 快速打卡（手机为主）

```
打开快速打卡（底部弹层）
↓
浏览器定位 → GET /geo/reverse（地点名、区域；60 米内且定位精度 ≤50 米时匹配旅行里的已知地点）
         → GET /geo/weather（打卡时刻天气，拿不到返回 null）
↓
用户可选照片 → 每张照片先上传到存储（原图 + 缩略图 + 中图），此时还没登记
↓
POST /trips/{id}/quick-checkins：打卡 + 天气快照 + 照片元数据在一个事务里保存
  （没有地点名时记为「随手记录」；定位 / 天气失败不影响保存）
```

## 4. 照片上传

```
POST /trips/{id}/photos/presign（检查 FREE 照片额度、大小 ≤20MB、类型）
↓
浏览器 PUT 原图到预签名地址；再分别为 thumb / medium 申请地址并上传（失败不影响原图）
↓
POST /trips/{id}/photos 登记（服务端确认对象确实存在）→ 触发成就计算
```

## 5. 分享

```
分享页选择成果 → 浏览器合成 PNG（Free 带水印，Pro 高清无水印）→ 下载
生成分享链接（有效期默认取用户设置：长期 / 7 天 / 30 天）→ 旅行 visibility 变为 UNLISTED
访客打开 /s/{token} → 只读页面（坐标默认粗化到约 1 公里，浏览次数 +1）
撤销链接 → 该旅行没有其他有效链接时恢复 PRIVATE
```

## 6. Travel Story 视频

```
新建视频项目（DRAFT）：选模板、照片、音乐、比例、时长、清晰度、开关
↓
预览分镜（POST /trips/{id}/video-storyboard，不保存）
↓
开始生成：重新校验全部条件（照片是否还在、套餐、模板、音乐、会员）→ 冻结分镜 → QUEUED
  └─ 同一用户同时最多 2 个任务排队 / 生成中，超过返回 429
↓
Worker 领取 → PROCESSING（PREPARING → … → UPLOADING）→ COMPLETED / FAILED
↓
完成：播放、下载；想修改 → 「重新编辑」复制出新的 DRAFT 版本；失败 → 重试（再次生成）
```

## 7. 付费

```
Trip Pro：POST /trips/{id}/payments/checkout
  ├─ PAYMENTS_MODE=mock（开发）→ 立即标记 PAID，旅行升级 PRO
  └─ stripe → 跳转 Stripe Checkout → Webhook（payment_status=paid）→ 标记 PAID，旅行升级 PRO
终身 Pro：POST /payments/lifetime/checkout → 付款成功后：users.lifetime_pro_at、该用户所有旅行升级 PRO、写入永久会员记录
```

## 8. 注销账号

```
设置 → 账户与安全 → 输入密码申请注销 → status=DELETION_PENDING，所有设备退出
↓（7 天冷静期内重新登录并确认 → 撤销注销）
到期 → 定时任务删除存储里该用户的文件（users/<id>/、user-music/<id>/）和账号（其余数据随外键级联删除，支付记录保留但 user_id 置空）
```
