# 功能模块设计

模块按业务划分；后端每个模块对应 `backend/api/src/main/java/com/tabitrace/<包名>/`，前端对应 `frontend/components/<目录>/` 和相关页面。模块之间的依赖规则见 [模块依赖设计](../03_architecture/02_模块依赖设计.md)。

| 模块 | 职责 | 后端包 | 前端 | 边界说明 |
|---|---|---|---|---|
| 账号与认证 | 注册、登录、会话、找回密码、登录限流 | `auth`、`verification`、`security`、`mail` | `app/login` `register` `forgot-password`、`components/auth`、`services/api.ts` | 只负责「你是谁」；资源归属在各业务模块里校验 |
| 用户与设置 | 资料、偏好、头像、改密码、设备管理、注销、账户概览 | `user` | `app/profile`、`components/settings` | 套餐与付款记录只读展示，修改在支付模块 |
| 会员 | 账号级会员资格（开通、到期判断） | `membership` | `components/membership/MembershipGate.tsx`、`utils/membership.ts` | 目前只控制「我的音乐」 |
| 旅行 | 旅行 CRUD、归档、完成、FREE 名额 | `trip` | `app/trips`、`app/trips/new`、`app/trips/[id]`、`components/trip` | 所有旅行内数据的归属校验入口（`TripService.requireOwned / requireWritable`） |
| 目的地与官方城市 | 目的地搜索、官方城市、官方地点、专题路线 | `destination`、`city` | `app/explore`、`components/explore`、`hooks/useExploreData.ts` | 官方内容只读，由迁移写入 |
| 地点 | 地点搜索、自定义地点、加入 / 移出旅行、收藏 | `place` | 地图页、推荐探索 | 官方与自定义地点共用 `places` 表 |
| 行程 | 计划地点（日期、时间、备注）、转打卡 | `itinerary` | 地图页 | 状态 PLANNED / DONE / CANCELLED |
| 打卡与时间轴 | 手动打卡、快速打卡、时间轴、最近记录 | `checkin`、`geo` | `components/checkin`、地图页、旅行详情 | 打卡会联动行程状态、旅行状态和成就 |
| 照片 | 上传授权、登记、照片墙、精选、封面、批量 | `photo`（含存储实现） | `app/trips/[id]/gallery`、`components/gallery` | 存储读写统一走 `StorageService` |
| 成就与总结 | 成就计算、旅行总结、成果准备度 | `achievement`、`summary` | `app/trips/[id]/achievements` `summary`、`components/achievements` | 统计实时计算，只持久化「获得成就」 |
| 分享 | 分享链接、公开分享页数据 | `share` | `app/trips/[id]/share`、`components/share`、`app/s/[token]` | 分享图在浏览器生成，后端只提供数据和导出规格 |
| 旅行视频 | 视频项目、分镜、模板与曲库、渲染队列、看门狗 | `video` + `backend/video-worker` | `app/trips/[id]/video`、`components/video` | API 只排队，渲染在 Worker |
| 我的音乐 | 会员上传音乐、试听、删除与清理 | `usermusic` | `components/video/music`、`hooks/useUserMusic.ts` | 依赖会员模块 |
| 支付与方案 | Trip Pro / 终身 Pro 付款、Webhook、方案配置 | `payment` | `app/pricing`、`components/pro` | 方案配置（价格、限制）唯一来源是 `PlanService` |
| 旅行回忆 | 回顾已完成的旅行 | `memory` | `app/memories`、`components/memories` | 只读聚合 |
| 首页与外壳 | 公共首页、登录后工作台、侧栏、顶栏、全局搜索、通知 | — | `app/page.tsx`、`components/landing` `home` `common` `mobile` | 通知由前端根据现有数据计算 |
| 开发工具 | 开发数据源切换（Local / Mock / Empty）、音乐版权后台 | `video/controller/DevMusicLicenseController`（只在 local profile） | `dev/`、`app/dev/music` | 生产构建与 prod profile 中不存在 |

## 横切能力

| 能力 | 位置 |
|---|---|
| 统一响应与异常 | `common/ApiResponse`、`BusinessException`、`GlobalExceptionHandler` |
| 坐标校验 | `common/validation/Latitude`、`Longitude` |
| 客户端 IP、哈希 | `common/ClientIp`、`Hashing` |
| 生产配置校验、仅迁移模式 | `config/ProductionSecretsValidator`、`MigrateOnlyRunner` |
| 多语言 | 前端 `i18n/`（部分界面） |
