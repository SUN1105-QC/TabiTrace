## V26 新增管理能力

- 新增用户采用真实邮箱邀请。受邀人仍在 `/register` 完成原有验证码验证并本人设置密码；邀请不自动创建账号。记录持久化，支持分页、重发、撤销；同一待处理邮箱唯一，重发间隔至少 1 分钟。撤销不禁止公开注册。发送失败返回 503，并回滚邀请记录 / 更新。
- 管理员单个 / 批量删除普通用户：校验微秒版本及目标完整邮箱，进入原有 7 天冷静期并撤销所有会话。新增 `deletion_requested_by_admin` 与 `deletion_previous_status`，用户不能通过登录自行撤销管理员安排的删除。管理员撤销后恢复原状态，原停用账号继续停用，旧会话继续失效。物理清理复用既有流程，唯一管理员受保护。
- 内容管理接服务端分页、名称 / 邮箱 / 目的地搜索、状态筛选、归档 / 取消归档、撤销全部公开分享、确认永久删除旅程。已到期旅程不会被恢复使用。
- 媒体管理提供照片 / 视频 / 用户音乐元数据分页与筛选，不返回存储密钥、私有资源地址或分享令牌。照片复用文件、尺寸版本及封面引用清理；生成中的视频禁止删除，其余视频保留持久化文件清理任务；音乐停止供新视频使用，活动生成结束后再清理文件。
- 系统设置可保存新注册账号默认等级、上限、保留月数和功能；初始仍为 20 条 / 1 个月。注册事务锁定默认设置，与管理员保存确定先后顺序；不批量回写已有账号。运行配置仅返回存储类型、邮件通道、Java 版本和成本限额白名单，绝不返回密钥或连接串。
- 审计日志接真实服务端分页及操作 / 内容 / 用户 ID 搜索。管理写入与留言回复共用管理员行锁、每分钟 60 次限制和成功审计。账号与旅程更新时间单调递增到微秒，避免同秒修改绕过版本检查。
- 维护任务持久化排队、最多一个活动任务，在独立线程执行有界的原有清理流程。结果保存暂时失败会重试；重启将中断的 RUNNING 任务标记失败，QUEUED 保留。当前面向单 API 实例；未来多实例需增加分布式租约，不能直接复制此调度器。

## 唯一管理员

- Flyway V25 为 `sunqingchuan1105@gmail.com` 初始化唯一管理员，密码只以 BCrypt 哈希保存。若该邮箱已存在，迁移将其提升为管理员并设置指定的初始密码、撤销既有会话。
- `users.role` 为 USER / ADMIN，生成列 `admin_slot` 的唯一索引在数据库层保证最多一个 ADMIN；应用没有新增管理员、转让角色或删除管理员的接口。
- 登录后管理员进入 `/admin`，只管理全站数据、用户权限与留言；普通用户不能访问 `/api/v1/admin/**`。管理员不能使用个人旅程接口。
- 每个访问令牌请求重新查询账号状态与角色，不信任前端字段。停用账号立即撤销全部会话；尚未到期的访问令牌也无法继续使用。
- 后台展示用户、有效旅程、照片、视频、排队任务、7 天内到期旅程、待清理旅程、待回复留言及已知媒体体积。体积不包括缩略图、对象存储实际账单。

## 用户权限

- 普通注册用户默认等级为“基础用户”，旅程上限 20、保留月数 1。管理员可以为每个账号设置等级名称、1～100000 条旅程、1～1200 个月，以及正常 / 停用状态。
- 配额统计所有尚未到期的旅程，包含归档与 Pro 旅程。新建时先锁定账号行，再统计与插入，避免并发突破上限。减少配额不会主动删除旅程，但达到上限时禁止新建。
- 可分别开关公开分享、视频制作；自定义音乐可选按会员权益、管理员开通或停用。管理员指定的音乐 ALLOW / DENY 优先于会员和全功能免费开关。账号配额与保留时间始终生效，Trip Pro / 终身 Pro / 免费开放开关均不绕过。
- 关闭公开分享后，既有公开链接也无法访问；视频功能关闭后仍可查看、下载和删除已有成果。备份导出始终可用。
- 权限变更和回复操作记录到 `admin_audit_logs`，含操作管理员、目标用户、操作内容和 UTC 时间。

## 到期与备份

- 旅程创建时记录 UTC `created_at` 和 `expires_at`，后者为创建时间加账号保留的自然月数，与出行日期、完成或归档时间无关。
- **V25 将已有旅程也按其原始创建时间加 1 个月回填。部署前需要备份并通知用户；超过期限的旧旅程会立即进入待清理状态。**
- 管理员调整月数后，尚未过期的旅程按原始创建时间重算。已经过期的旅程不会因升级而复活；缩短月数可能导致立即到期。
- 到期立即拒绝旅程访问，回忆中心也过滤过期内容。API 每分钟检查最多 200 条并删除关联数据、该旅程独占的自定义地点、照片原图 / 缩略图 / 中图及暂存上传。视频输出通过原有持久化清理队列交给 Worker 删除。失败记录日志并在下一轮重试。API / Worker 需要保持运行。
- 页面始终显示账号配额、保存规则和当前旅程到期时间；到期前 7 天持续显示站内提醒。没有新增邮件通知。
- `GET /api/v1/trips/{id}/export` 流式返回 ZIP：`trip.json`（旅程、打卡、行程、地点、照片和视频元数据）、`photos/` 原图、`README.txt`、`export-report.json`。报告列出无法读取的照片。视频二进制仍需在视频页面单独下载；导出时持有账号锁，防止清理任务删除下载中的照片。
- 财务支付 / 渠道审计数据沿用 V20 保留规则，不因旅程到期删除。

## 留言与接口

用户从 `/support` 查看权限、备份旅程并给管理员留言。每账号每日最多 10 条，主题最多 120 字、正文 / 回复最多 5000 字；用户只看自己的最近 100 条留言，管理员每页 25 条、支持待回复 / 已回复筛选。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/v1/admin/overview` | 全站监控概览 |
| GET | `/api/v1/admin/users?q=&status=&page=1&pageSize=25` | 邮箱 / 昵称搜索、状态筛选；每页 10 / 25 / 50 条，默认 25，ID 降序 |
| GET | `/api/v1/admin/users/{id}` | 最新普通用户详情、真实头像及微秒 updatedAt |
| PUT | `/api/v1/admin/users/{id}` | 调整等级、配额、保存月数、功能与状态；附 expectedUpdatedAt，返回保存后的用户详情 |
| GET | `/api/v1/admin/messages?status=OPEN&page=1` | 留言管理，状态也可 REPLIED 或留空 |
| GET | `/api/v1/admin/messages/page?status=OPEN&page=1` | 带 items / total / page / pageSize 的留言分页；保留原数组接口 |
| POST | `/api/v1/admin/messages/{id}/reply` | 提交 / 更新回复 |
| GET / POST | `/api/v1/support/messages` | 查看本人留言 / 提交留言 |
| GET | `/api/v1/trips/{id}/export` | 下载本人未过期旅程 ZIP |

新增错误：`ADMIN_REQUIRED`、`ADMIN_PROTECTED`、`FEATURE_DISABLED`（403）；`TRIP_LIMIT_REACHED`（409）；`TRIP_EXPIRED`（410）；`MESSAGE_LIMIT`（429）；`MESSAGE_NOT_FOUND`（404）。

2026-11-15 管理页重构：权限写入使用账号行锁内的 `expectedUpdatedAt` 比较，过期草稿返回 `ADMIN_USER_CHANGED`（409），不能静默覆盖。客户端须原样回传用户详情中的微秒时间戳，不能用 JS Date 截断精度。管理员行锁将权限写入串行化，每分钟最多 60 次成功修改，超过返回 `ADMIN_UPDATE_LIMIT`（429）；成功权限变更与回复审计追加操作标识 requestId 和 SUCCESS 结果。等级、配额、月份和权限字段不合法返回 `INVALID_USER_PERMISSIONS`（400），非法筛选 / 分页返回 `INVALID_PAGE_FILTER`（400）。无新迁移，继续使用 V25 的现有列和审计表。尚未发布的管理功能需同步更新前后端，旧开发客户端须刷新后读取并回传并发令牌。

页面移除缺少业务能力的新增用户、批量操作与删除入口；手机端使用原生模态编辑抽屉，缩短期限 / 停用账号前确认，切换用户 / 页面 / 返回时保护未保存草稿。完整映射、源码清单和验收见 [用户管理页面重构](../08_testing/13_用户管理页面重构验收_2026-11-15.md)。
