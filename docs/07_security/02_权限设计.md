# 权限设计（你能做什么）

## 1. 模型

**没有角色和管理后台**。权限由三层决定，规则细节以 [用例与业务规则](../02_business/03_用例与业务规则.md) 为准：

| 层 | 依据 | 作用 |
|---|---|---|
| 登录 | Spring Security（无状态 JWT） | 除公开路径外都要登录 |
| 资源归属 | Service 层按 `currentUser.id` 校验 | 只能访问自己的旅行及旅行内数据、自己的视频、自己的音乐 |
| 权益 | `trips.plan_type`（旅行级）、`memberships`（账号级） | FREE / PRO 限制；会员功能 |

## 2. 公开路径（`SecurityConfig`）

| 路径 | 原因 |
|---|---|
| `/api/v1/auth/**` | 注册、登录、刷新等 |
| `/api/v1/share/**` | 匿名查看分享（凭令牌） |
| `/api/v1/local-storage/**` | 本地存储模式的上传 / 读取（凭 HMAC 签名，私有文件一律要签名或不可读） |
| `/api/v1/payments/stripe/webhook` | Stripe 回调（凭签名） |
| `/api/v1/plans/**` | 方案配置（升级页未登录也要显示价格） |
| `GET /api/v1/official-cities/**`、`GET /api/v1/places/search` | 推荐探索未登录可浏览 |
| `/actuator/health` | 健康检查 |

其余全部需要登录。

## 3. 资源归属

| 资源 | 校验 |
|---|---|
| 旅行 | `TripService.requireOwned`（不存在 404 / 别人的 403）；写操作用 `requireWritable`（另外拒绝已归档旅行） |
| 打卡、照片、行程、地点关联、分享链接、成就、总结 | 通过所属旅行校验 |
| 视频项目 | 校验 `user_id`，再校验所属旅行可写 |
| 照片存储路径 | 必须在 `users/{当前用户}/trips/{该旅行}/` 下 |
| 自定义地点 | 必须已关联到当前旅行 |
| 我的音乐 | 校验 `user_id`；试听只发短时签名地址 |
| 登录设备 | 只能看到、退出自己的会话 |

**匿名分享访问**（例外）：不登录，必须持有有效、未过期、未撤销的令牌；只返回允许公开的字段，不返回邮箱和设置，坐标默认粗化。

## 4. 前端路由保护

| 路由 | 保护方式 |
|---|---|
| `/trips/**`、`/profile` | 布局里的 `SessionGate`：确认登录前不渲染，未登录跳登录页 |
| `/memories` 等其他需要数据的页面 | API 返回 401 → `services/api.ts` 跳登录页 |
| `/s/[token]` | 公开；令牌无效显示失效页 |
| `/dev/music` | 生产环境 404 |

前端判断只用于体验；**所有限制都在后端执行**。

## 5. 权益矩阵（摘要）

| 能力 | FREE 旅行 | PRO 旅行 | 需要会员 |
|---|---|---|---|
| 打卡 / 照片 | 各 10 | 不限 | — |
| 分享图 | 标准 + 水印 | 高清无水印 | — |
| Travel Story | 720p、≤30 秒、10 张、FREE 模板与音乐 | 1080p、≤60 秒、30 张、全部模板与音乐 | — |
| 上传自己的音乐 | — | — | 是（目前只有终身 Pro 开通） |

数值见 [枚举与常量](../04_data/03_枚举与常量定义.md) §2。
