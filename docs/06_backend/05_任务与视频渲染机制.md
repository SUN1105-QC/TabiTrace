# 任务与视频渲染机制

项目**没有消息队列**。异步工作分两类：API 内的定时任务，和以数据库表为队列的视频渲染（ADR-002）。

## 1. API 定时任务（`@Scheduled`）

| 任务 | 位置 | 频率 | 作用 |
|---|---|---|---|
| 视频看门狗 | `video/service/VideoRenderWatchdog` | 每 60 秒 | PROCESSING 超过 300 秒没有心跳 → FAILED / `RENDER_INTERRUPTED` |
| Mock 渲染器 | `video/service/VideoMockRenderer` | 每 2.5 秒 | **只在 `VIDEO_MOCK_RENDERER=true` 时**：把 QUEUED 直接标为 COMPLETED（地址不可播放，`renderer=MOCK`） |
| 注销到期删除 | `user/service/AccountDeletionService` | 每小时第 23 分 | 删除冷静期已过的账号与其存储文件 |
| 会话清理 | `auth/service/SessionCleanupService` | 每小时第 47 分 | 删除过期 / 撤销超过 7 天的 refresh token（每批 5000） |
| 登录失败清理 | `auth/service/LoginThrottleService` | 每小时第 37 分 | 删除过期的登录失败记录 |
| 验证码清理 | `verification/service/EmailVerificationService` | 每天 03:17 | 删除 7 天前的验证记录 |
| 我的音乐清理 | `usermusic/service/UserMusicCleaner` | 每 10 分钟 | 删除超时未完成的上传；在相关视频生成结束后删除已删除 / 失败音乐的文件 |

cron 都可以用 `app.*.cleanup-cron` 等配置覆盖。⚠ 多个 API 实例同时运行时，这些任务会在每个实例上各跑一次（没有分布式锁）；目前单实例部署，没有问题。

## 2. 视频渲染

### 生产者：API（`VideoService.render`）
1. 校验：旅行可写、该项目不在 QUEUED / PROCESSING、用户同时进行的任务 < 2、照片仍存在，并**重新校验**全部套餐与会员条件。
2. 用 `StoryboardService` 生成分镜（开场 → 地点段 → 成就 → 结尾，按模板节奏分配时长，总时长等于所选时长），至少要有一个照片段。
3. 把分镜连同音乐片段（起点、增益、音量、署名、原曲路径）冻结进 `storyboard_json`。
4. 条件更新为 `QUEUED`（并发提交时只有一次成功）。

### 消费者：Worker（`backend/video-worker`）
| 步骤 | 说明 |
|---|---|
| 领取 | 每 5 秒查 `status='QUEUED' ORDER BY id LIMIT 1`，用 `UPDATE … WHERE id=? AND status='QUEUED'` 抢占（多个 Worker 也不会重复领取），置 PROCESSING / `PREPARING` |
| 心跳 | 每 15 秒更新 `updated_at`，供 API 看门狗判断 |
| 渲染 | 读冻结分镜 → 下载照片原图（`photos.image_url`，不用缩略图）和音乐 → `ScenePainter`（Java2D）画每个画面 → `FfmpegRenderer` 合成、混音；FREE 加水印；需要署名的音乐在片尾写署名 |
| 超时 | 单次 FFmpeg 调用最长 600 秒，超时强制结束 |
| 上传 | `render_stage=UPLOADING` → 成片写入存储（R2 或本地 `frontend/public/generated-videos`） |
| 完成 | COMPLETED + `output_url`；有提示（如音乐降级）写 `render_warning` |
| 失败 | FAILED + `error_code` / `error_message`，清空工作目录 |
| 停机 | 收到 SIGTERM 不再领取新任务；当前任务最多再等 `WORKER_SHUTDOWN_GRACE_SECONDS`（默认 20 秒），否则中断 FFmpeg、清理文件，把任务放回 QUEUED |
| 启动自检 | 报告 FFmpeg 是否可用、字体能否显示中文、音乐目录是否存在；清扫上次遗留的中间文件 |

### 重试与幂等
- 用户对 FAILED / COMPLETED 的项目再次点生成 → 重新校验并重新入队（新的冻结分镜）。
- 音乐文件不可用时不失败，降级为无音乐（`MUSIC_FALLBACK` 提示）。
- 前端轮询项目状态显示进度，没有 WebSocket。

### 限制与注意
- Worker 启动时的清扫假设**只有一个 Worker 实例**；多实例需要每个实例配置独立的 `VIDEO_WORK_DIR`。
- 本地开发跑真实 Worker 时必须让 API 关闭 Mock 渲染器，否则 Mock 会先抢走任务（启动脚本找到 FFmpeg 时会自动处理）。
- Linux 服务器必须安装中文字体（Dockerfile 已包含），否则成片中文显示为方块。
- 成片删除问题见 [文件存储设计](04_文件存储设计.md) §6。
