# 后端架构设计

代码：`backend/`（Maven 多模块，父 POM `tabitrace-backend`）。Java 21、Spring Boot 4.1.1。

## 1. 模块

| 模块 | 说明 |
|---|---|
| `api`（`tabitrace-api`） | REST API，端口 8080（生产读 `PORT`），前缀 `/api/v1`；启动时执行 Flyway 迁移；内含定时任务 |
| `video-worker`（`tabitrace-video-worker`） | 视频渲染进程，没有 HTTP 端口；JDBC 直接读写 `video_projects`；调用 FFmpeg |

两个模块**不共享代码**，只通过数据库和对象存储交换数据。

## 2. API 内部分层

```
Controller（@RestController，只做参数绑定与 SecurityUtils.currentUser()）
   ↓
Service（@Service，业务规则、归属校验、事务 @Transactional）
   ↓
Mapper（MyBatis 注解：@Select / @Insert / @Update，没有 XML）
   ↓
MySQL
```

| 层 | 约定 |
|---|---|
| 包结构 | 按功能分包 `com.tabitrace.<功能>.{controller,dto,entity,mapper,service}`；模块清单见 [功能模块设计](../02_business/02_功能模块设计.md) |
| DTO | Java record，集中写在 `XxxDtos.java`；请求用 Jakarta Validation 注解（`@NotBlank`、`@Size`、自定义 `@Latitude / @Longitude`） |
| Entity | 公有字段的简单类，字段名与列名 camelCase 对应 |
| 响应 | 统一 `ApiResponse<T>(success, data, code, message)`；Jackson `non_null` |
| 错误 | 业务错误抛 `BusinessException(code, message[, status[, details]])`，由 `GlobalExceptionHandler` 转换，见 [异常与错误码](03_异常与错误码设计.md) |
| 认证 | `security/JwtAuthenticationFilter` 解析访问令牌并检查会话仍有效；当前用户 `SecurityUtils.currentUser()` |
| 存储 | `photo/storage/StorageService` 接口，`app.storage.mode` 选择实现（local / r2 / mock），见 [文件存储设计](04_文件存储设计.md) |
| 配置 | `application.yml`（默认）+ `application-local.yml` + `application-prod.yml`；全部可用环境变量覆盖，见 [环境与配置](../09_deployment/01_环境与配置说明.md) |

## 3. 横切组件

| 组件 | 位置 | 作用 |
|---|---|---|
| `SecurityConfig` | `config/` | 无状态、关闭 Spring CSRF、CORS 白名单、公开路径、BCrypt；不使用 Spring 的用户名密码体系 |
| `ProductionSecretsValidator` | `config/` | prod profile 启动时校验必要变量，缺失或是开发默认值就拒绝启动（只报变量名） |
| `MigrateOnlyRunner` | `config/` | `--app.migrate-only=true` 时只执行迁移然后退出 |
| `ClientIp` | `common/` | 取客户端 IP（可信代理时取 `X-Forwarded-For` 最右侧，否则只信本机 nginx 的 `X-Real-IP`） |
| `Hashing` | `common/` | HMAC / SHA-256（验证码、令牌、IP 只存哈希） |
| 定时任务 | 各模块 Service | 见 [任务与视频渲染机制](05_任务与视频渲染机制.md) |

## 4. 外部调用

| 调用 | 位置 | 说明 |
|---|---|---|
| Stripe | `payment/service/StripeGateway` | REST 调用创建 Checkout；Webhook 用签名校验 |
| 邮件 | `mail/MailService` | `app.mail.provider`：smtp（Spring Mail）或 resend（HTTPS API） |
| 逆地理 / 天气 | `geo/service/GeoService`、`WeatherService` | Nominatim、Open-Meteo；失败返回 null，不报错 |
| 对象存储 | `photo/storage/R2StorageService` | AWS SDK v2 S3 客户端 |

## 5. 没有的东西

没有服务端缓存（Redis / `@Cacheable`）、没有消息队列、没有 OpenAPI 文档生成、没有连库的集成测试（只有 Mockito 单元测试，依赖里的 H2 未被使用）。
